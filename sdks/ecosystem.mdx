| | What it is | Where |
|---|---|---|
| **Node.js SDK** | Typed client for supported operations, zero dependencies, Node 18+ | [Docs](/sdks/node) · [npm](https://www.npmjs.com/package/nixflex) · [GitHub](https://github.com/nixflex/nixflex-node) |
| **Python SDK** | Sync and async clients, Python 3.9+ | [Docs](/sdks/python) · [PyPI](https://pypi.org/project/nixflex/) |
| **CLI** | `npx nixflex` - supported operations from a terminal, `--json` for scripts | [Docs](/cli/overview) · ships in the `nixflex` package |
| **MCP server** | Your account as tools for Claude Desktop, Cursor, VS Code | [Docs](/mcp/overview) · [npm](https://www.npmjs.com/package/nixflex-mcp) |
| **OpenAPI spec** | OpenAPI 3.1 - import into Postman, or generate a client for any language | [public.openapi.json](https://docs.nixflex.com/api-reference/public.openapi.json) · [Other languages](/sdks/other-languages) |
| **API reference** | Public operations, examples, and error guidance | [Reference](/api-reference/introduction) |
| **Web call widget** | One script tag that adds a "call us" button to a website | [Web calls](/concepts/web-calls) |
| **Webhooks** | Signed post-call events, five retries | [Webhooks](/advanced/webhooks) |

These tools use the public API. Some dashboard workflows use separate internal or signed-in interfaces. Check operation coverage before choosing a client.
