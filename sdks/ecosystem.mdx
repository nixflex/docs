These tools use the public API. Some dashboard workflows use separate internal or signed-in interfaces. Check operation coverage before choosing a client.

## Calendar and carrier credential operations

The API now includes Google Calendar connect, status, settings and disconnect, plus in-place phone-number credential updates. Use the server HTTP examples in [Google Calendar](/api-reference/integration-settings/google-calendar) and [number credentials](/api-reference/phone-numbers/credentials) until your installed client release documents those methods. A successful API deployment does not publish a package or register a new MCP tool. Existing tool counts describe the reviewed kit version only.

Single-SMS suppression now uses HTTP 409 `do_not_contact` instead of 400 `invalid_request`. Preserve that code in error handling and do not retry a known opt-out.
