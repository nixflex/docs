## Prerequisites

Keep `NIXFLEX_API_KEY` private on the server and choose the matching API host. Use owned identifiers; SDK and CLI examples need the [exact reviewed candidate](/sdks/ecosystem). Replace `agent_example` with an owned agent. This update changes future agent behaviour.

## 1. Read the current settings

Read the agent and any relevant number override before changing shared behaviour. A prompt alone cannot grant an action capability.

## 2. Save the intended setting

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

The menu wait defaults to 240 seconds, accepts 1–1,800 seconds through the public API and is capped by the applicable maximum call duration. Use a longer maximum only when the task needs it.

## 3. Write a narrow instruction

Describe the destination role and likely menu choices. Supported menu tags such as `[IVR]`, `[PRESS: 1]` and `[IVR_END]` mark the wait, send a keypad choice and return to normal conversation. Ask the agent to stop navigating once a human answers.

## 4. Test the actual outcome

Test the exact menu with permission, including a changed option, hold music and no human answer. Menu prompts and speech recognition can vary. Do not promise a path will work from a transcript alone.

## 5. Review the result

Read back configuration after a confirmed update. Inspect the call and action result separately; a saved switch is not proof a real business action succeeded. If a write response is lost, reread the object before repeating it.

## Example response

The agent update returns the safe saved agent projection. Check the intended fields in a fresh [agent read](/api-reference/agents/get); call outcomes are separate records.

## Errors and limits

| Condition | Handling |
| --- | --- |
| Menu wait expires | Read the resulting end reason; do not claim a human was reached. |
| Human detected | Leave menu mode and continue the actual task. |
| Maximum call duration earlier | The shorter applicable cap wins. |
| Website visitor | Telephone-menu actions are unavailable. |
