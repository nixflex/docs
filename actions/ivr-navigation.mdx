Let an outbound agent navigate a telephone menu before speaking with a person. Menu navigation is a telephone capability, separate from receiving keypad input.

Using the dashboard? See [the business guide](/guides/business/call-actions).

## Prerequisites

Keep the account credential in `NIXFLEX_API_KEY` on your server. The supplied client candidates are Node/CLI 0.11.0 and Python 0.4.0. Use the matching reviewed archive; a registry install alone does not establish that these methods are available. See the [client release guidance](/sdks/ecosystem). Set all identifiers and the API host for the intended account and environment. Replace `agent_example` with an owned agent. This update changes future agent behaviour.

## 1. Read the current settings

Read the agent and any relevant number override before changing shared behaviour. A prompt alone cannot grant an action capability.

## 2. Save the intended setting

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

<CodeGroup>

```bash cURL
curl --fail-with-body --request PUT \
  --url "https://api.nixflex.com/v1/agents/agent_example" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"ivr_timeout_seconds":240}'
```

```javascript Node
const response = await fetch('https://api.nixflex.com/v1/agents/agent_example', {
  method: 'PUT',
  headers: { Authorization: `Bearer ${process.env.NIXFLEX_API_KEY}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({"ivr_timeout_seconds":240}),
});
const result = await response.json();
if (!response.ok) throw new Error(JSON.stringify(result));
console.log(result);
```

```python Python
import os, json
from urllib.request import Request, urlopen

request = Request(
    'https://api.nixflex.com/v1/agents/agent_example',
    method='PUT',
    headers={'Authorization': 'Bearer ' + os.environ['NIXFLEX_API_KEY'], 'Content-Type': 'application/json'},
    data='{"ivr_timeout_seconds":240}'.encode('utf-8'),
)
with urlopen(request, timeout=30) as response:
    print(json.load(response))
```

```powershell CLI (PowerShell)
nixflex agents update agent_example --set ivr_timeout_seconds=240 --json --base-url https://api.nixflex.com
```

</CodeGroup>

The menu wait defaults to 240 seconds, accepts 1–1,800 seconds through the public API and is capped by the applicable maximum call duration. Use a longer maximum only when the task needs it.

## 3. Write a narrow instruction

Describe the destination role and likely menu choices. Supported menu tags such as `[IVR]`, `[PRESS: 1]` and `[IVR_END]` mark the wait, send a keypad choice and return to normal conversation. Ask the agent to stop navigating once a human answers.

## 4. Test the actual outcome

Test the exact menu with permission, including a changed option, hold music and no human answer. Menu prompts and speech recognition can vary. Do not promise a path will work from a transcript alone.

## 5. Review the result

Read back configuration after a confirmed update. Inspect the call and action result separately; a saved switch is not proof a real business action succeeded. If a write response is lost, reread the object before repeating it.

## Example response

The agent update returns the safe saved agent projection. Check the intended fields in a fresh [agent read](/api-reference/agents/get); call outcomes are separate records.

## Errors and limits

| Condition | Handling |
| --- | --- |
| Menu wait expires | Read the resulting end reason; do not claim a human was reached. |
| Human detected | Leave menu mode and continue the actual task. |
| Maximum call duration earlier | The shorter applicable cap wins. |
| Website visitor | Telephone-menu actions are unavailable. |
