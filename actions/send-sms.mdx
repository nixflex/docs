Texting is split into three pages, one per moment:

- [In-call SMS](/actions/in-call-sms) - text the caller while the call is happening, with the `[SEND_SMS:]` tag. Includes booking confirmations.
- [Post-call SMS](/sms/post-call-sms) - text automatically once the call has ended, from an agent template or your own webhook.
- [Send SMS](/sms/send-sms) - send a message via the API with no call involved. Also covers message length, tracking, carrier support, compliance and pricing.

When a customer texts back, the [SMS agent](/sms/sms-agent) answers. For the same message to many numbers, see [SMS campaigns](/sms/sms-campaigns).
