## Prerequisites

Keep `NIXFLEX_API_KEY` private on the server and choose the matching API host. Use owned identifiers; SDK and CLI examples need the [exact reviewed candidate](/sdks/ecosystem). Review whether the sending number is dashboard-origin or API-origin.

## 1. Read current configuration

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

## 2. Choose detection deliberately

`amd_enabled` controls the optional early answering-machine detection path. Recognition and timing vary. Enabling this can terminate a machine-answered call before a later leave-message path has a chance to run.

## 3. Set a short message

When leave-message is enabled, supply nonblank `voicemail_message`. Dashboard-origin numbers use the agent policy. API-origin numbers use their own enable/message without fallback to the agent. A valid message is not proof it will be delivered to every answering system.

## 4. Test the actual destination behaviour

Use an approved test mailbox and listen to the saved message. Test a long greeting, no tone, human answer and early detection. Do not promise fixed detection times or perfect human/machine classification.

## 5. Read the call outcome

Check the recorded end reason and available events. Automatic post-call SMS skips detected voicemail. Do not use an uncertain voicemail result as an instruction to repeatedly call or text the recipient.

## Example response

Read the saved `amd_enabled`, `voicemail_leave_enabled` and `voicemail_message` fields at their applicable scope. Actual call outcomes are separate from these configuration values.

## Errors and limits

| Condition | Handling |
| --- | --- |
| Leave-message on with blank text | Supply a valid message. |
| Early detection ends call | Do not assume leave-message also ran. |
| API-origin number | Configure its own voicemail fields. |
| Unknown classification | Review the result before another contact. |
