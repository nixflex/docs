Website voice lets a visitor talk to the agent through the installed widget and their browser microphone. It uses the number's website configuration and is separate from an ordinary telephone call.

## Saved switches and effective voice

Website voice requires both `web_agent_enabled` and `web_calls_enabled`. Turning the Web agent off leaves the saved voice preference unchanged but prevents effective voice access. Account, agent, balance and current admission checks also apply.

Website instructions are separate from phone and SMS instructions. Knowledge belongs to the agent; website voice and website chat have independent knowledge switches. Visitor contact fields are self-reported, not verified identity. Recognition can end when browser storage changes.

## Public visitors and actions

The number's `web_functions_enabled` switch defaults off. Enabling it permits that number's enabled custom functions after current checks. Every enabled function must therefore be suitable for a public visitor. This does not enable built-in calendar booking, SMS, transfers, keypad or telephone-menu navigation.

## Installation and testing

Use the dashboard's generated Install snippet and current environment configuration. Do not copy an old SDK script or expose an account key in the browser. An install-not-ready message means the snippet cannot yet be supplied for that environment.

A successful preview does not test the final website's microphone permissions, browser storage, embedding restrictions or contact collection. Test the installed site with fictional contact details and approved test actions.
