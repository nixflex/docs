title: "Agent voices: choose a voice and understand saved settings"
description: "Choose a Nixflex voice from the current catalog and understand how saved voice settings affect conversations, without assuming every channel sounds alike."
---

Every voice conversation uses an eligible voice selection. The agent supplies a default; number overrides have field-specific rules. Website voice shares audio settings, while website chat has no spoken voice.

## Catalog voices and legacy aliases

The agent's `voice_key` selects a catalog entry. Its `voice_id` is a legacy alias and can be null for a catalog-only voice. A conflicting key and alias are refused. Use the current [voice catalog](/api-reference/voices/get-voices) and its supported languages rather than copying a fixed list of display names.

On a legacy selection path, the number's voice alias can override the agent alias. In catalog mode, a non-null agent catalog key takes priority over that alias. A number alias is not automatically converted into a catalog override. Custom voice and fallback paths can also change what is actually heard.

## Speaking rate

Use `speaking_rate` for speed. An explicit number value wins over the agent; null inherits. Setting a number to 1 explicitly requests normal speed, while null under a faster agent still inherits that faster value. The older `voice_speed` field is accepted for compatibility but does not control current speech output.

The ordinary rate range is 0.5–1.5 and runtime clamps apply. The audible effect depends on the selected route. Test a small adjustment with names, dates and a full conversation instead of assuming identical speed across every voice.

## Language and fallback

A display name does not prove language coverage. Use the eligible catalog entry and intended agent language. Unsupported combinations or dependency failures can use a different supported path, so the same voice identity is not guaranteed in every fallback situation.

Changes apply to new work. A saved selection proves configuration, not that every future call will use it successfully. Listen to a real approved test call, including a permitted action and an interruption, before relying on the setting with customers.
