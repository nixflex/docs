An organisation lets people share agents, phone numbers, work and balance while using their own logins. The role applies to that organisation; a personal login is not its shared API credential.

| Capability | Owner | Admin | Member |
| --- | --- | --- | --- |
| Read shared work | Yes | Yes | Yes |
| Change agents, numbers and campaigns | Yes | Yes | No |
| View Nixflex amounts, Billing and Activity | Yes | Yes | No |
| Manage Members | Yes | Yes | No |
| Manage Admins | Yes | No | No |
| Reveal or rotate the shared key | Yes | No | No |
| Offer ownership or close the organisation | Yes | No | No |
| Eligible live Listen and takeover | Yes | Yes | Yes |

Server checks enforce permissions. Member is not a write role, but eligible live call controls are a deliberate exception. Removing access can leave disconnection pending; a committed human takeover may retain only the controls needed to finish that one call.

## Invitations and ownership

Invites expire after 24 hours. Default limits are 50 seats including unexpired pending invites and 20 new or resent invites per UTC day. Resending replaces the old link. Admins can invite and manage Members only.

Ownership is offered from Team and accepted by the recipient through their own login. Recent verification can be required. The former Owner becomes an Admin after successful transfer. An offer is not a completed transfer.

## Keys, leaving and closure

A shared API key has account authority. Giving it to a Member does not create a restricted Member credential. Key rotation and personal membership changes are separate operations. Organisation signing credentials can also be separate from API access.

Leaving removes a membership, not the person's login. Account closure uses the personal Owner dashboard flow. The old `/v1/account/delete` exposure returns `410 dashboard_owner_required`; there is no replacement API-key closure workaround. Closure locks new work while cleanup is tracked; accepted closure is not proof every external operation or retained object has already disappeared.
