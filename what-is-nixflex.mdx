Nixflex provides configurable business agents for telephone calls, SMS and website conversations. An agent can answer questions and use permitted actions, such as checking a connected calendar or sending an allowed text.

## The main parts

| Part | Purpose |
| --- | --- |
| Agent | Shared call behaviour, voice, language, time zone and knowledge |
| Phone number | Call and message address, channel switches and number-specific connections |
| Knowledge | Reviewed topics from text, files or website sources |
| Campaign | A reviewed set of people to contact for a specific purpose |
| Organisation | Shared business work with Owner, Admin and Member access |
| Inbox and history | Current conversation and call records, subject to retention |

Knowledge belongs to the agent and is shared by its attached numbers. Use separate agents when different businesses need different answers. Each channel has its own instructions and permissions; website visitors cannot automatically use every telephone action.

## Dashboard or code

The dashboard provides setup, team, billing, monitoring and conversation screens. The public API provides the documented account, agent, number, campaign, knowledge and integration workflows. Some personal actions, such as ownership acceptance, need the person's signed-in dashboard flow.

Calls and messages pass current account, contact and capacity checks. Accepted work is not the same as a connected call, delivered text or successful booking. Read actual outcomes and test your intended workflow before using it with customers.
