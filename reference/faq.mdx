Short answers to the questions people ask most. Each links to the full detail.

## Getting started

<AccordionGroup>
  <Accordion title="Do I need to write code to use Nixflex?">
    No. Developers can use the [API](/api-reference/introduction), and businesses can set everything up in the dashboard — start with the [guides](/guides). Both paths use the same platform underneath.
  </Accordion>
  <Accordion title="How long does it take to get set up?">
    You can have an agent answering real calls in a few minutes. The [Quickstart](/quickstart) walks through it end to end.
  </Accordion>
  <Accordion title="Do I need my own phone number?">
    Yes — Nixflex is bring-your-own-carrier. Your numbers stay in your own Twilio or Telnyx account, and you connect them to Nixflex. See the [Quickstart](/quickstart).
  </Accordion>
  <Accordion title="Which carriers are supported?">
    Twilio and Telnyx. Everything works the same on either one. See [Phone numbers](/concepts/phone-numbers).
  </Accordion>
</AccordionGroup>

## Capabilities

<AccordionGroup>
  <Accordion title="Can it handle both inbound and outbound calls?">
    Yes — the same agent handles [inbound calls](/concepts/inbound-calls) and [outbound calls](/concepts/outbound-calls).
  </Accordion>
  <Accordion title="Can one number do voice and text?">
    Yes. The same number is a call agent and an SMS agent — when someone texts, your AI replies automatically. See [SMS agent](/sms/sms-agent).
  </Accordion>
  <Accordion title="Can the agent book appointments?">
    Yes, when you connect a calendar. The agent checks availability and books live during the call. See [Cal.com](/actions/calcom) or [Google Calendar](/actions/google-calendar).
  </Accordion>
  <Accordion title="What languages are supported?">
    Fifteen languages, with automatic switching across ten of them. Arabic, Hebrew, Korean, Chinese, and Polish are fully supported but the agent must be locked to them. See [Languages](/concepts/languages).
  </Accordion>
  <Accordion title="Can visitors talk to the agent on my website?">
    Yes — add the web agent for voice and chat in the browser, no phone number needed. See [Web agent](/web-assistant/overview).
  </Accordion>
</AccordionGroup>

## Pricing and billing

<AccordionGroup>
  <Accordion title="How much does it cost?">
    Voice is a flat \$0.08 per minute. Calls someone listened to with Live Monitor, and calls placed from the browser, bill at \$0.09 per minute - enabling either feature costs nothing, and calls that do not use it stay at \$0.08. Web chat is \$0.01 per message. Full detail on the [Pricing](/reference/pricing) page.
  </Accordion>
  <Accordion title="Are there setup fees or monthly minimums?">
    No setup fees, no monthly minimums, and no per-feature charges. See [Pricing](/reference/pricing).
  </Accordion>
  <Accordion title="How does billing work?">
    Pay-as-you-go from a credit balance you top up (minimum \$5), with optional auto-top-up so you never run out mid-call. See [Pricing](/reference/pricing).
  </Accordion>
  <Accordion title="What do I pay my carrier directly?">
    Phone numbers, carrier voice minutes, and SMS messages are billed by your own Twilio or Telnyx account — Nixflex never marks them up. See [Pricing](/reference/pricing).
  </Accordion>
</AccordionGroup>
