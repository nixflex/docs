Knowledge base is available in the dashboard. Add text, upload a supported file or select website pages, then review and approve the topics you want your agent to use. Knowledge belongs to the agent and is shared by its attached phone numbers.

Start with the [Business Knowledge guide](/guides/business/knowledge) for the complete steps. Owners and Admins can make changes; Members can read.

## What you can do

- Review proposed topics before publishing, and test real questions without making a call, sending a text or creating a booking.
- Edit or remove live topics and review refreshed website content. Deleting a source's last live topic also removes the source and its retained original.
- See **From your knowledge** keyterm chips in agent settings, and add up to 20 words or phrases of your own.
- Use **Download a copy** for live topic text and settings, or **Download for developers** for the fuller JSON copy. These downloads do not contain original uploaded files.

For integration details, read [Manage knowledge with the API](/guides/developer/knowledge). Keep essential conversation rules in the agent's [main instructions](/concepts/agent-prompts); use knowledge for the detailed business facts it needs to answer questions.
