Set up an AI phone agent to answer business calls and help customers find the right next step. Start with one clear job, such as answering service questions or taking appointment requests, then test it before adding more responsibilities.

## Before you start

- Sign in to the Nixflex dashboard as Owner or Admin.
- Have an active business phone number and current business facts ready.
- Choose a test phone and a team member who can review the results.

## Steps

### 1. Create an agent

Open **Agents** and choose **Create agent**. Give it a name your team will recognise. Choose a voice and language suitable for the customers you serve; listen to the preview before saving.

<Note>Screenshot placeholder: **business-agent** — Agents, Create agent with name and voice selected. Use staging test data.</Note>

### 2. Write its instructions

Explain who the agent represents, how it should speak and what to do when it cannot help. Include your most-used facts. Asking the agent to book does not connect a calendar: complete that setup separately before promising bookings.

### 3. Add business knowledge

Open **Knowledge base**, choose the agent and add your text, files or website pages. Review the proposed topics before approving them. All numbers attached to this agent share its knowledge, so use separate agents for different branch answers.

### 4. Connect your number

Open **Phone Numbers**, choose **Import number**, complete the connection fields and select your agent. Check the number is active and its inbound switch is on. Import changes call routing, so plan when the existing answering service should stop.

<Note>Screenshot placeholder: **business-number** — Phone Numbers, connected test number with attached agent and inbound switch. Use staging test data.</Note>

### 5. Make a test call

Call the number from your test phone. Ask a normal question, an unknown question and a request for a person. Open **Call History** afterwards and check what happened. Correct instructions or knowledge before widening use.

## What happens next

Your agent answers eligible incoming calls using its instructions, number settings and enabled knowledge. Keep checking early calls so you can fill factual gaps and improve unclear directions.

## Common questions

### Can I change the agent later?

Yes. Edit it and save. Most settings affect new calls; knowledge edits have their own publication checks.

### Can I move the number?

Yes. Use **Move number** on Phone Numbers. Wait if the number is busy; you do not need to remove and import it again.

### Does everyone on my team edit it?

Owners and Admins can edit shared work. Members can review it and use permitted live-call controls.
