**FIXED · account** `DELETE /v1/calls` covers the owning account’s calls and related recordings. It takes no number or campaign filter. Its result reports sms_deleted=0.

**NOT OFFERED → do this instead · number** There is no bulk erase for just one customer’s number in a shared account. Resolve and verify each tenant-owned call ID, then use single-call deletion.

**YOU CAN CHANGE · agent** New agents inherit account retention on creation. Use the agent update to change its saved call-retention policy.

**SCOPE · call** Check recording availability first. A stored link can expire. Pending, expired, unavailable and customer-bucket states have different meanings.
