**FIXED · platform** **MUST** Use `[SEND_SMS: message]` only when the agent’s `incall_sms_enabled` is on. For transfer use `[TRANSFER: phone_number]`.\
The other actions are `[WAIT]`, `[END_CALL]` and the outbound-only menu controls `[IVR]`, `[PRESS: digits]`, `[IVR_END]`. For another action configure a booking integration or custom function.

**NOT OFFERED → do this instead · platform** You cannot register a new action tag in a prompt. For your own workflow, configure a number-level custom function with defined arguments.

**YOU CAN CHANGE · recipient** Use case-sensitive ASCII letters, digits and underscores for names such as `{{pickup_time}}`. Send dynamic_vars for one call. Map CSV columns to recipients[].variables for each campaign row. Supply caller_name and business_name when referenced.

**SCOPE · call** Outbound uses its call purpose for developer instructions. Inbound combines the shared agent instructions with the dialled number’s profile. Engine rules and eligible knowledge can also apply.
