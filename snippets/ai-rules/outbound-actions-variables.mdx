**FIXED · platform** Use the listed developer-facing outbound tag forms exactly. The IVR and keypad navigation forms are outbound only. `[SEND_SMS: message]`, `[TRANSFER: phone_number]`, `[WAIT]`, `[END_CALL]`, `[IVR]`, `[PRESS: digits]`, `[IVR_END]`.

**NOT OFFERED → do this instead · platform** Developers cannot add or rename an action tag. Use the supported tag. For a custom integration, configure a custom function on the number and have the agent use the tool.

**YOU CAN CHANGE · recipient** Choose case-sensitive ASCII letters, digits and underscores, for example `{{appointment_time}}`. Use dynamic_vars on a single call and map CSV columns to recipients[].variables for each campaign row. Supply caller_name and business_name yourself when referenced. Validate every row before submitting.

**SCOPE · call** Outbound uses its call purpose for developer instructions. Inbound combines the shared agent instructions with the dialled number’s profile. Engine rules and eligible knowledge can also apply.
