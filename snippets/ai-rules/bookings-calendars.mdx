**FIXED · call** For a new Google Calendar or Cal.com voice booking, collect and spell contact details separately, finish the combined read-back, then obtain a later clear yes for that proposal. Confirm the booking only after a successful write. This applies even with require_booking_confirmation=false.

**NOT OFFERED → do this instead · number** Cal.com does not offer an independent general call timezone for each number. It checks the agent timezone, its integration fallback, then Europe/London. Use separate agents for different Cal.com agent timezones. Google Calendar honours an explicit number-calendar timezone first, then uses the agent resolution.

**YOU CAN CHANGE · number** Supported Google Calendar settings include availability hours, timezone and invitation behaviour. These configure that number’s booking calendar. `timezone`, `hours`, `slot_minutes`, `calendar_id`, `send_invites`.

**SCOPE · number** For an owned number assigned to an agent, send only return_url to start Google Calendar consent. Open the returned url for the calendar owner. A competing calendar is refused. Read the number’s status after consent to confirm connection.
