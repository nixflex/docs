**FIXED · agent** Language, general call timezone, pickup delay and fixed welcome_message belong to the agent. Numbers share those settings.

**NOT OFFERED → do this instead · number** A number cannot set a separate fixed welcome_message, language, general timezone or pickup delay. Use another agent for distinct settings. For a different business opening on the same agent use Dynamic greeting and the number prompt.

**YOU CAN CHANGE · agent** Choose the supported catalogue voice and an eligible route. Select manual speech terms or configure structured values to extract from transcripts.

**SCOPE · number** A configured primary/backup number voice pair wins as a whole. Inherit to use the agent pair. On legacy paths a number voice_id can clear an agent catalogue key. An incompatible partial pair can be unavailable.

A developer can run many customers on one shared agent. Give each customer its own number and number prompt. Separate agents are needed only when knowledge or agent settings must differ.

Agents are unlimited. There is no fee per agent. Customers pay only for usage (minutes and texts).

For a different greeting per business, keep Dynamic greeting on (the default) and put the opening line in that number’s custom_prompt. For example, “Start every call with: Thank you for calling Oak and Stone”.
