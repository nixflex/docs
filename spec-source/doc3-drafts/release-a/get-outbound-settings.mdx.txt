Check whether a single outbound call needs an explicit sender when the agent has two or more settled numbers on this account.

<div className="nxf-facts">
  <div><small>Method</small><strong>GET</strong></div>
  <div><small>Scope</small><strong>Organisation</strong></div>
  <div><small>Result</small><strong>Current setting</strong></div>
</div>

<div className="nxf-important">

**The important part**

- The default is `false`. With `true`, two or more settled numbers on the same agent make `from_number` required, even if only one can make outbound calls.
- Imports still in progress are excluded. An explicitly supplied number must belong to the account, be assigned to the agent and pass the usual outbound checks.
- This setting applies to single calls. Campaigns use their saved sender.

</div>

## Authentication

Use the organisation API key on your server or a verified personal session for an active Owner, Admin or Member. Each reads only their own organisation. The organisation feature must be enabled.

## Request fields

Send no request body. No query parameters are needed.

## Response fields

`200 OK` returns the setting for the authenticated account.

| Field | Type | Meaning |
| --- | --- | --- |
| `require_from_number_for_shared_agent` | boolean | Current value. A new account starts with `false`. |

## Example request

Use the account’s credential from a private server environment.

<RequestExample>

```bash cURL
curl --request GET \
  --url "https://api.nixflex.com/v1/organisation/outbound-settings" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY"
```

</RequestExample>

## Example response

<ResponseExample>

```json 200
{
  "require_from_number_for_shared_agent": false
}
```

</ResponseExample>

## Retry and idempotency

This is a read. A bounded retry is safe. Another authorised writer can change the value between reads.
