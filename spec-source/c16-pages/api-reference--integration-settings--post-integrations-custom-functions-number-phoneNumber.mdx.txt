Create one function for an owned number. Each number can have at most 15 functions; names must be unique for that number.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential. When personal dashboard sessions are enabled, Owner and Admin sessions can write these settings; Member sessions can read only. Ownership checks still apply. Send `Content-Type: application/json`.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | None | Owned E.164 number. URL-encode the leading plus sign. |

Send a JSON object.

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `name` | string | Yes | None | Lowercase snake_case function name. Maximum 64 characters. Pattern: `^[a-z][a-z0-9_]*$`. |
| `description` | string | No | `""` | Description supplied to the agent. |
| `url` | string | Yes | None | HTTPS destination; required on create. |
| `method` | string | No | `"POST"` | Uppercased before validation. Allowed: `"GET"`, `"POST"`, `"PUT"`, `"PATCH"`, `"DELETE"`. |
| `headers` | object | No | `{}` | Private HTTP headers. GET returns only has_headers. |
| `parameters` | object | No | `{"type":"object","properties":{}}` | Function parameter JSON schema. |
| `speak_during` | string or null | No | `null` | Optional phrase; a falsey value clears it. |
| `timeout_ms` | integer | No | `5000` | Parsed as an integer and clamped to 1,000–45,000 ms. Zero or nonnumeric values fall back to 5,000. |
| `is_active` | boolean | No | `true` | Only literal false disables the function. |

Headers are private and never returned by the list route. Timeout inputs are parsed and clamped; the stored range is 1,000–45,000 ms. A supplied falsey description becomes an empty string, falsey headers become an empty object, falsey parameters restore the default schema, and falsey speak_during clears the phrase.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `ok` | boolean | Request succeeded. Value: `true`. |
| `id` | string | Function identifier. |
| `phone_number` | string | Owned phone number. |
| `name` | string | Saved function name. |

## Example request

Examples require Node/CLI 0.11.0 or later, Python 0.4.0 or later and MCP 0.5.0 or later. Keep `NIXFLEX_API_KEY` in your private process environment. The cURL example uses Bash. Use approved owned fixtures and keep configuration responses private. Python shows sync usage; AsyncNixflex uses the same method with async with and await. Configure the existing MCP installation for the same account at `https://api.nixflex.com`. Save the request JSON fields from the example below in request-46.json privately before using cURL or CLI; replace fixture credentials only in that private file. Review the target and payload before this write.

```json request-46.json
{
  "name": "lookup_fixture",
  "url": "https://example.invalid/tool",
  "method": "POST",
  "headers": {
    "X-Fixture": "private_fixture_value"
  },
  "parameters": {
    "type": "object",
    "properties": {}
  },
  "speak_during": null,
  "timeout_ms": 0,
  "is_active": false
}
```

<RequestExample>

```bash cURL
curl --request POST \
  --url "https://api.nixflex.com/v1/integrations/custom-functions/number/%2B12025550123" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY" \
  --header "Content-Type: application/json" \
```

```javascript Node
import { Nixflex } from 'nixflex';
```


## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 500 | [`server_error`](/api-reference/errors#server_error) | The result could not be confirmed. | Read the current state before retrying a write. |
| 400 | [`invalid_phone`](/api-reference/errors#invalid_phone) | The number is not valid E.164. | Correct the request before retrying. |
| 404 | [`not_found`](/api-reference/errors#not_found) | No matching owned resource or saved configuration was found. | Check the identifier and owning account. |
| 400 | [`invalid_url`](/api-reference/errors#invalid_url) | The destination URL is not accepted. | Use the required HTTPS destination. |
| 400 | [`invalid_name`](/api-reference/errors#invalid_name) | The function name is invalid. | Correct the request before retrying. |
| 400 | [`invalid_method`](/api-reference/errors#invalid_method) | The HTTP method is not accepted. | Correct the request before retrying. |
| 409 | [`duplicate_function`](/api-reference/errors#duplicate_function) | Another function on this number uses that name. | Correct the request before retrying. |
| 400 | [`limit_reached`](/api-reference/errors#limit_reached) | The number already has 15 functions. | Remove an unused function before creating another. |
| 400 | [`invalid_json`](/api-reference/errors#invalid_json) | The JSON body could not be parsed. | Correct the request before retrying. |
| 413 | [`payload_too_large`](/api-reference/errors#payload_too_large) | The request body is too large. | Reduce the request body. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the full account credential. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

No idempotency token is supported. Read the function list after a timeout before resending. Creation can conflict with an existing name, and repeating a delete may remove a function recreated under the same ID.
