## Prerequisites

Ask the organisation Owner for the full account credential through your approved secret-storage process. Store it as `NIXFLEX_API_KEY`; never include it in browser code, source control, screenshots or logs.

## 1. Choose the account

Use `https://api.nixflex.com/v1` with the full credential for your account. Keep it in `NIXFLEX_API_KEY` on your server.

## 2. Read usage

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

<CodeGroup>

```bash cURL
curl --fail-with-body --request GET \
  --url "https://api.nixflex.com/v1/usage" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY"
```

```javascript Node
const response = await fetch('https://api.nixflex.com/v1/usage', {
  method: 'GET',
  headers: { Authorization: `Bearer ${process.env.NIXFLEX_API_KEY}` },
});
const result = await response.json();
if (!response.ok) throw new Error(`HTTP ${response.status}: ${result.error?.code || 'unknown'}`);
// Use the result privately; do not log account or caller data.
```

```python Python
import os, json
from urllib.request import Request, urlopen

request = Request(
    'https://api.nixflex.com/v1/usage',
    method='GET',
    headers={'Authorization': 'Bearer ' + os.environ['NIXFLEX_API_KEY']},
)
with urlopen(request, timeout=30) as response:
    result = json.load(response)
# Use the result privately; do not log account or caller data.
```

```powershell CLI (PowerShell)
nixflex usage --json --base-url https://api.nixflex.com
```

</CodeGroup>

## 3. Check the result

A successful JSON response includes account usage and `max_concurrent`. Preserve optional and null fields. Capacity occupancy can include unresolved reservations, so it is not simply the number of connected calls.

## 4. Handle errors before adding writes

Use the error table below before adding a mutation. A failed usage read must stay unavailable; it must not become an empty account in your UI.

## 5. Choose one business workflow

Create or select an owned agent, attach an eligible number for telephone work, then follow the task guide. A call or campaign example can contact people; use approved recipients and review its outcome before repeating it.

## Example response

Illustrative fields from a successful response:

```json
{"plan":null,"total_calls":0,"total_minutes":0,"total_cost":0,"max_concurrent":10}
```

Ten is the current legacy fallback, not a promise of this account’s limit. Use the returned value.

## Errors and limits

| Result | Next step |
| --- | --- |
| 401 | Fix authentication and host selection. |
| 429 | Respect the effective rate limit and retry guidance. |
| Optional capacity fields absent | Use available fields without inventing occupancy. |
| Usage differs from Billing | Usage counters are not an invoice or complete charge ledger. |
