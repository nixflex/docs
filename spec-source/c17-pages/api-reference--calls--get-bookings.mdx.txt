## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `id` (path) | string | Yes | Owned call identifier. Invalid, missing and foreign identifiers share the same 404. At most 200 characters |

Do not send a request body.

This read does not contact a calendar or place a call. Invalid, missing and foreign call IDs share one 404. A retained result describes this call, not the current calendar. It uses the same public projection as [call.bookings](/api-reference/call-bookings), without a delivery signature. The response uses Cache-Control: no-store.

## Response fields

`200 OK` returns `call_id`, `state` and `result`. The response is `Cache-Control: no-store`.

| State | Result | What to show |
| --- | --- | --- |
| ready | Confirmed object | Show timeline and final from the retained result of this call. |
| none | null | No successful mutation, established by complete booking evidence. |
| processing | null | Tracked call or post-call work is unfinished; offer a bounded refresh. |
| deleted | null | Content was removed, immediately scheduled for deletion, expired or is being purged. |
| unavailable | null | Old, partial or unconfirmed evidence; no definitive booking result. |

For ready, result has the complete [call.bookings payload](/api-reference/call-bookings#payload). Count active rows in final; timeline counts actions. This is not the current calendar inventory. Do not infer none from a transcript, an empty legacy array or an unsuccessful call.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status / code | What it means | What to do |
| --- | --- | --- |
| 401 · `unauthorized` | The credential is missing or invalid. | Check the full account credential and API host privately; stop the retry loop. |
| 403 · `permission_denied` | This actor cannot perform the operation. | Resolve the account or role restriction through an authorised person. |
| 404 · `not_found` | Call identifier is invalid, missing or foreign. Check the owned ID. | Check the exact owned identifier and current resource state; do not probe another account. |
| 429 · `rate_limit_exceeded` | The request limit was reached. | Wait at least Retry-After and use a bounded read retry. |
| 503 · `call_bookings_unavailable` | The read failed. Retry the read with bounded backoff; never show none. | Retry the read with bounded backoff. Keep the result unavailable; never display none. |

A 503 call_bookings_unavailable is a failed read, not none. Keep the last known uncertainty and use bounded read retries. A 404 does not reveal another account’s calls.

## Retry and idempotency

This read does not place a call or change a booking. Retry temporary read failures with bounded backoff. Refresh processing only within a chosen time limit; preserve deleted and unavailable as distinct results. This endpoint is not paginated.
