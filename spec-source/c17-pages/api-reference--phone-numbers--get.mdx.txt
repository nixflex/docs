## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | The number in E.164 format. URL-encode the leading + as %2B. |

Do not send a request body.

Use E.164 and URL-encode the leading plus: `/v1/phone-numbers/%2B12025550100`.
Requires an active API key/account. Unknown numbers, other accounts, pending imports
and internal browser-test numbers all return `404 number_not_found`.

The response is `{ "phone_number": { ... } }`. Every field below is present;
unset saved overrides remain null. This is not a dump of the database row.

| Fields | Meaning |
|---|---|
| `phone_number`, `agent_id`, `provider`, `created_at` | Public number, assigned public agent identifier, carrier and creation date |
| `source` | Read-only `api` / `dashboard`; null for unknown legacy origin. Descriptive, not a permission |
| `inbound_enabled`, `outbound_enabled`, `sms_reply_enabled` | Incoming calls, outbound call permission, automatic SMS replies |
| `web_agent_enabled`, `web_calls_enabled`, `web_functions_enabled`, `monitor_enabled` | Saved website and monitoring switches |
| `web_calls_effective` | Read-only website voice switch eligibility: saved voice ON and Web agent not OFF |
| `record_call`, `recording_source` | Saved recording override and source; null inherits agent |
| `custom_prompt`, `sms_prompt`, `web_prompt` | Separate call business profile, SMS instructions and website instructions |
| `voice_id`, `speaking_rate`, `dtmf_enabled`, `require_booking_confirmation` | Saved voice, speed, keypad and booking-confirmation overrides |
| `voicemail_leave_enabled`, `voicemail_message` | Saved per-number voicemail; dashboard-origin numbers use the agent policy instead |
| `telnyx_key_status` | Safe status below; no full key or full fingerprint |

Effective voice is only a switch calculation, not a guarantee that a call can start.
Account/agent activity, billing, authorization and existing admission checks still apply.
Legacy null Web agent values retain the existing engine's enabled interpretation.
No value is written by this request; it never changes the saved voice switch.

### Telnyx key status

Same projection as the dashboard:



`fingerprint` is at most 16 characters; the previous-key deadline is null when
absent/expired. `set` and `verified` describe stored key state, not provider health.
Twilio numbers normally have false/false/null/null key metadata.

To install or rotate a Telnyx signature key, send `telnyx_public_key` through the
existing import/PATCH candidate flow. A successful save is NOT verification.
Only the engine's valid signed-callback flow can verify a candidate; read back this
status after the normal callback test. There is no API field to force verified.
See [update](/api-reference/phone-numbers/update) and [import](/api-reference/phone-numbers/import).

Credentials, carrier account secrets, full signature keys, full fingerprints,
internal row/account/import IDs and operation tokens are never returned.

## Example request

Production HTTP examples. Replace the placeholder identifiers with resources owned by the account. Set `NIXFLEX_API_KEY` privately; never print it.

<RequestExample>

```bash cURL (Bash)
  --header "Authorization: Bearer $NIXFLEX_API_KEY"
```

```javascript Node (HTTP)
const response = await fetch('https://api.nixflex.com/v1/phone-numbers/%2B12025550123', {
```

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status / code | What it means | What to do |
| --- | --- | --- |
| 400 | Invalid E.164 phone number. | Correct the named field or query using the request table before trying again. |
| 401 | Invalid key or inactive account. | Check the full account credential and API host privately; stop the retry loop. |
| 404 · `number_not_found` | The number is absent or inaccessible to this account. | Check the exact owned identifier and current resource state; do not probe another account. |
| 429 | Rate limit exceeded. | Wait at least Retry-After and use a bounded read retry. |
| 500 | Database read failed, not an empty successful result. | Keep the last result unknown and use bounded read retries; do not replace it with empty data. |



## Retry and idempotency

Use bounded retries only for temporary read failures. Keep the same filters while paging. See [retry rules](/api-reference/retries).
