## Prerequisites

Keep `NIXFLEX_API_KEY` private on the server and use `https://api.nixflex.com`. Use owned identifiers; SDK and CLI examples need the [exact reviewed candidate](/sdks/ecosystem). Choose an owned SMS-capable number and current agent.

## 1. Read number settings

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

## 2. Write the SMS instructions

PATCH the number with `sms_prompt` containing the business facts, purpose, reply style and action boundaries for text. The prompt limit is 20,000 characters. Do not put a private API credential or unsupported action into instructions.

## 3. Enable the reply switch

Set `sms_reply_enabled:true` deliberately. The number, account, agent and current message checks must still permit a reply. Turning off replies does not delete the conversation or stop separately requested outbound messages.

## 4. Connect knowledge and permitted booking

Enable the agent knowledge SMS channel if saved topics should be used. Calendar actions need their eligible connection and real results. Campaign reply context can add information during its association window; do not assume the outgoing message automatically rewrites the SMS prompt.

## 5. Review a test conversation

Use an approved test sender, ask a known question, ask an unknown one and check any booking outcome in the calendar. Read the SMS conversation through the inbox. An accepted reply is not proof the handset received it.

## Example response

The saved number object shows `sms_reply_enabled` and `sms_prompt`. Reread after a confirmed PATCH; safe projections omit credentials. Inbox responses provide conversation records separately.

## Errors and limits

| Condition | Handling |
| --- | --- |
| Prompt too long | Reduce it below 20,000 characters. |
| Replies off | Enable deliberately after preparing instructions. |
| Knowledge missing | Review live topics and the SMS channel switch. |
| Calendar refusal | State the actual failure; do not confirm a booking. |
| Archived thread | Archive affects inbox state, not the reply switch. |
