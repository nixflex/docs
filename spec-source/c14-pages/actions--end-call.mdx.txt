## Prerequisites

Keep `NIXFLEX_API_KEY` private on the server and choose the matching API host. Use owned identifiers; SDK and CLI examples need the [exact reviewed candidate](/sdks/ecosystem). Replace `agent_example` with an owned agent. This update changes future agent behaviour.

## 1. Read the current settings

Read the agent and any relevant number override before changing shared behaviour. A prompt alone cannot grant an action capability.

## 2. Save the intended setting

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

<CodeGroup>

```bash cURL
curl --fail-with-body --request PUT \
  --url "https://api.nixflex.com/v1/agents/agent_example" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"func_end_call":true,"silence_hangup_seconds":10,"max_call_duration_seconds":300}'
```

```powershell CLI (PowerShell)
nixflex agents update agent_example --set func_end_call=true --set silence_hangup_seconds=10 --set max_call_duration_seconds=300 --json --base-url https://api.nixflex.com
```

</CodeGroup>

New agents default to 10 seconds of silence and a 300-second maximum. Existing saved values remain. `func_end_call:false` disables the configured silence/duration timers; it does not prohibit every model-requested `[END_CALL]` or other hangup path.

## 3. Write a narrow instruction

Explain when the task is complete and ask for a short goodbye followed by `[END_CALL]`. A model instruction is guidance rather than a guarantee. A person, connection failure or other lifecycle event can also end the call.

## 4. Test the actual outcome

Test a normal goodbye, prolonged silence and the maximum duration. Read `ended_reason` and terminal state after the call. A control request accepted by a server is not itself confirmation the connection has ended.

## 5. Review the result

Read back configuration after a confirmed update. Inspect the call and action result separately; a saved switch is not proof a real business action succeeded. If a write response is lost, reread the object before repeating it.

## Example response

The agent update returns the safe saved agent projection. Check the intended fields in a fresh [agent read](/api-reference/agents/get); call outcomes are separate records.

## Errors and limits

| Setting | Current boundary |
| --- | --- |
| New-agent silence / duration | 10 / 300 seconds. |
| Public API explicit timer values | Positive whole seconds up to 2,147,483; null handling is field-specific. |
| Dashboard sliders | Can offer a narrower range than the API. |
| func_end_call false | Disables configured timers, not every possible hangup. |
| Post-call work | Recording, analysis and event delivery can finish separately. |
