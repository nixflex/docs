## Prerequisites

Use an owning account credential and active agent. Replace fixture IDs and numbers with owned test values. Country and time zone are optional overrides when you know the recipient’s location; never substitute the business’s time zone for an unknown recipient.

## 1. Request a bounded preview

<CodeGroup>

```bash cURL
curl --request POST \
  --url "https://api.nixflex.com/v1/contact-hours/preview" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"agent_id":"agent_fixture","recipients":[{"phone":"+12025550101","country":"US","timezone":"America/New_York"}]}'
```

## 2. Read the server result

Use `as_of`, `expires_at`, `hold_reason`, `display_reason`, `message`, `next_allowed` and `next_unavailable`. A next time can be null. The preview covers 1–20 recipients, expires after 60 seconds and has a bounded future search. Multiple possible zones can constrain the result.

## 3. Read suppressions

GET `/v1/contact-suppressions` for the intended channel. `both`, `voice` and `sms` are separate scopes. Distinguish owner-added entries from `sms_optout`, and preserve `removal_locked` rather than offering a remove button for every row.

## 4. Change business entries deliberately

Use the documented POST/DELETE routes for business-added suppressions. A locked recipient opt-out cannot be removed by the business. If management is paused, existing opt-outs stay enforced; a refusal must not be displayed as removal.

## 5. Handle dispatch refusals

Single calls and SMS can refuse with `do_not_contact`, `needs_timezone` or `outside_hours`; campaigns hold affected recipients. Show the reason. Use `not_sent`/`charged:false` only when the response explicitly proves a pre-dispatch refusal. Unknown results need reconciliation, not automatic resend.

## Example response

Preview replies describe current guidance and any next allowed time. `advisory_only` identifies that this is not dispatch permission. Render the safe `message` as text and refresh after expiry; do not replace a failed preview with a local guess.

## Errors and limits

| Condition | Handling |
| --- | --- |
| Preview expired/unavailable | Request fresh guidance; retain unknown state. |
| Invalid country/time zone | Correct the supplied override. |
| 409 contact refusal | Respect the hold and correct the source information. |
| 503 `feature_paused` | Management is paused; existing opt-outs still apply. |
| Wider-hours request | Use only with permission and a valid reason; hard limits still apply. |

## Single-SMS suppression response change

Single `POST /v1/sms` now returns **409 `do_not_contact`**, type `conflict`, when the recipient is suppressed. It previously returned **400 `invalid_request`**. Nothing was sent. Stop and respect the opt-out; never automatically retry or remove the suppression. SMS campaigns still hold affected recipients individually with `hold_reason: do_not_contact`.
