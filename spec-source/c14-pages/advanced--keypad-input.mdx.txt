## Prerequisites

Keep `NIXFLEX_API_KEY` private on the server and choose the matching API host. Use owned identifiers; SDK and CLI examples need the [exact reviewed candidate](/sdks/ecosystem). Choose the agent and number that should accept keypad input.

## 1. Read number settings

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

<CodeGroup>

```bash cURL
curl --fail-with-body --request GET \
  --url "https://api.nixflex.com/v1/phone-numbers/%2B12025550100" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY"
```

## 2. Enable the input control

Set the supported `dtmf_enabled` value on the agent or number. Read the field’s inheritance rule before assuming an agent change applies to every number. Keypad input is separate from an agent sending menu choices.

## 3. Ask for only needed digits

Explain what code is needed and how to finish, such as pressing the hash key. Do not request payment secrets or broad credentials through a generic conversation flow. Check expected length and format in your business action.

## 4. Test completion and corrections

A hash key completes the entry; an idle interval can also submit buffered digits. Test the actual telephone route, incomplete entries and a caller correcting a mistake. Do not assume every device or connection delivers every tone.

## 5. Verify before acting

Read back suitable non-sensitive details or ask again when ambiguous. An entered reference is not authorisation to access another person’s records. Apply separate verification at the service that performs the action.

## Example response

The saved settings describe whether input is enabled. Received digits become conversation input; they are not a standalone public API delivery receipt or proof of account ownership.

## Errors and limits

| Condition | Handling |
| --- | --- |
| No digits received | Offer a supported spoken or human fallback. |
| Partial/wrong-length entry | Ask again rather than guessing. |
| Website visitor | Built-in telephone keypad input is unavailable. |
| Sensitive action | Apply independent business verification. |
