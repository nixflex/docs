## Scope and permissions

Many integrations belong to a phone number. Pre-call hooks also support an agent default with number precedence. Moving a number preserves number-owned connections, while the inherited agent behaviour and knowledge change. Read the specific integration's rule rather than assuming all settings copy together.

Calendar and custom-function actions need actual permission and valid arguments. Website visitors have restricted built-in actions; enabling their custom functions requires every enabled function on that number to be safe for public visitors.

## Configuration is not completion

A successful save means the configuration was accepted. It does not prove a future calendar write, notification or external automation succeeded. Test an ordinary result and a failure, preserve uncertain states and reconcile before repeating side effects.

Incoming event receivers should verify signatures and deduplicate durable work. External copies have their own retention. Disconnecting a connection or deleting a Nixflex call does not automatically erase a record already sent to another system.
