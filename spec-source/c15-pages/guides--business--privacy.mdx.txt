<div className="nxf-important">

**The important part**

- The account default applies to new agents; review existing agents separately.
- Call retention does not control every message, contact card or caller-memory record.
- Downloads, your own bucket and connected tools can retain separate copies.
- Leaving a team removes membership. It does not close the organisation or erase its work.

</div>

## Before you start

- Use Owner or Admin access for shared settings; only the Owner can close the organisation.
- Decide what data your business needs and where you keep separate copies.

## Steps

<Steps>

<Step title="Review the account default">

<span id="1-review-the-account-default" />

Open **Settings** and review the call-data retention default. New agents inherit it. Changing that default does not rewrite the choices already saved on existing agents.

</Step>

<Step title="Check each agent">

<span id="2-check-each-agent" />

Open an agent and review **Keep call data for**. Choices include 90, 30, 7 or 1 day, and deletion after each call. Zero-day cleanup waits for required final work; it does not interrupt a live conversation.

</Step>

<Step title="Download available data">

<span id="3-download-available-data" />

In **Settings → Data and privacy**, use the data download control. Keep the resulting file private. It contains supported account records, not secrets or the original recording files. Download recordings separately from Call History and payment documents from Billing.

</Step>

<Step title="Review other copies">

<span id="4-review-other-copies" />

Check your own recording bucket, downloaded files and connected tools. Nixflex’s automatic retention does not remove your own bucket files. Caller memory, website contact cards and message retention are separate from the call setting.

</Step>

<Step title="Choose the right leaving action">

<span id="5-choose-the-right-leaving-action" />

Use **Leave organisation** if you are an Admin or Member leaving the team. Only the Owner can use **Delete account** to request closure. Read the confirmation carefully and complete any fresh sign-in checks. Closure locks the organisation while cleanup is tracked.

</Step>

</Steps>

## What happens next

Review the displayed status until work is confirmed. Pending cleanup is not completed erasure. Required billing and trial-protection records can remain, and personal logins survive organisation closure.

## Check what each action changes

| What you see | What it means | What to do |
| --- | --- | --- |
| Default saved | New agents inherit the default. | Check existing agents individually. |
| Data download available | Supported account records can be downloaded. | Keep the file private; recordings and payment documents are separate. |
| Organisation cleanup pending | Closure is not yet completed erasure. | Review the displayed status; required records can remain. |
| Membership removed | That person has left the shared organisation. | Review any separately shared keys or copied files. |

## Common questions

<AccordionGroup>

<Accordion title="Does leaving delete shared work?">

No. It removes your membership; the organisation keeps its work and balance.

</Accordion>

<Accordion title="Does disabling caller memory erase saved details?">

No. Stopping future memory use is separate from deleting existing records.

</Accordion>

<Accordion title="Can I close the organisation using a shared key?">

No. Closure requires the Owner’s personal dashboard login.

</Accordion>

<Accordion title="Are all messages kept for the call period?">

No. Check the channel-specific retention policy; the call setting is not a universal retention control.

</Accordion>

</AccordionGroup>

## Delete content deliberately

Deleting one call hangs it up first if it is still running, then removes its content. An Owner or Admin can delete; a Member cannot. A confirmed content deletion can still have queued recording cleanup. Nixflex recording cleanup does not certify carrier erasure or remove customer-managed copies. Used charges and required financial records remain, with no refund.

Deleting a voice or SMS campaign cancels waiting work, hangs up its running calls, then removes the campaign and recipient list. Calls already made and texts already sent stay in history. Used charges stay in billing; there are no refunds. Owner and Admin can delete; Member cannot. Cancel alone stops future dispatch and lets active calls finish; Delete also requests their hang-up.

Read [delete call data](/guides/business/privacy/delete-call-data) for the dashboard task and [single-call deletion](/api-reference/calls/delete) for response fields.
