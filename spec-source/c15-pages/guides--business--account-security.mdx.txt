## Enable two-factor authentication

1. Sign in and open **Settings → Security**.
2. Choose **Enable** beside **Two-factor authentication**.
3. Scan the QR code in your authenticator app. If scanning is unavailable, enter the displayed setup key privately in that app.
4. Enter its current six-digit code and choose **Verify & enable**.
5. Wait for **Enabled** before treating setup as complete. Signing in will require a code from the authenticator.

## Add a backup authenticator

Choose **Add backup** in the same Security section. Set it up on a different app or device and verify the code. When it shows **Active**, either configured authenticator can be used at sign-in. Do not store the setup secret in agent instructions, a shared document or an AI chat.

## Keep team access separate

Invite each teammate with their own login and the role their work requires. Members can manage their own login security without receiving shared editing or billing access. Leaving an organisation removes membership, not the person's login.

An organisation API key is a separate server credential with Owner authority. Two-factor protection on your login does not make a copied API key safe to share.

## Fix a sign-in problem

| Problem | What to do |
| --- | --- |
| Code rejected | Use the current code for the correct Nixflex entry and check the device clock. |
| Authentication settings could not be checked | Use Retry; do not assume protection is off. |
| First authenticator unavailable | Use the verified backup authenticator. |
| Both authenticators unavailable | Contact support@nixflex.com. Do not expect a teammate to bypass your authentication. |

Disabling protection is a deliberate change in the same Security section. Keep at least one working sign-in method and read the confirmation before changing it.
