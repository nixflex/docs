## Create the agent

1. Open **Agents** as Owner or Admin and choose **Create agent**.
2. Enter a recognisable business or team name and create it.
3. Open the agent and write its job, greeting, key facts and the point at which a person should help.
4. Choose the language, voice and time zone for the intended conversations.
5. Review recordings, caller memory and retention separately; one privacy switch does not control all saved data.

## Give each setting a home

| Need | Where to work |
| --- | --- |
| Role, tone and common call facts | [Agent instructions](/guides/business/agents/instructions) |
| Detailed menus, policies or uncommon answers | [Knowledge base](/guides/business/knowledge) |
| Speaking style and language | [Voice and language](/guides/business/agents/voice-and-language) |
| Telephone routing and channel switches | [Phone Numbers](/guides/business/phone-numbers) |
| SMS or website instructions | The selected number’s SMS or Web agent setup. |
| Bookings or transfers | The corresponding connection and [call action](/guides/business/call-actions). |

Use separate agents when branches need different knowledge. Changing shared agent behaviour affects attached numbers unless a documented number override applies.

## Check the result

Save the settings, reopen the agent and check the intended number assignment. Test a known answer, an unknown answer and a human handoff. Deleting an agent switches it off; it does not erase its call history or automatically remove every number connection.
