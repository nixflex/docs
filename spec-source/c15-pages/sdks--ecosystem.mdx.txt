## Choose by task

| Tool | Use it for | Runtime and guide |
| --- | --- | --- |
| Node SDK | Typed server integrations and local outbound preparation | Node 18+; [Node guide](/sdks/node). |
| Python SDK | Synchronous or asynchronous server applications | Python 3.9+, httpx; [Python guide](/sdks/python). |
| CLI | Reviewed terminal operations and scripts | Ships in the Node package; [CLI quickstart](/cli/quickstart). |
| MCP server | Approved AI-client tool operations | Node 22+ for the server; [MCP developer guide](/sdks/mcp). |
| Direct HTTP | Another language or a method not exposed by your installed client | [Other languages](/sdks/other-languages) and [API reference](/api-reference/introduction). |

The website widget uses its generated installation flow, not a server SDK in the browser. Webhook processing is an HTTPS receiver you build; installing a client does not create one.

## Install a client

| Client | Minimum version for these examples | Install or run |
| --- | --- | --- |
| Node SDK | 0.11.0 | `npm install nixflex` |
| CLI | 0.11.0 | `npm install -g nixflex` |
| Python SDK | 0.4.0 | `pip install nixflex` |
| MCP server | 0.5.0 | `npx -y nixflex-mcp` |

Use the setup guide for your client to configure the account credential privately and use `https://api.nixflex.com`. The MCP server needs Node 22 or later; the Node SDK and CLI need Node 18 or later. Python needs version 3.9 or later.

## Understand the added call workflow

The reviewed clients support local outbound preparation, a saved request UUID, a read-only request-state lookup and a read-only post-call booking result. Preserve the same account, base URL, UUID and inputs across reconciliation. The request-state lookup cannot place a call.

Node uses `prepareOutboundCall`, `calls.outboundRequest` and `calls.bookings`. Python uses `prepare_outbound_call`, `calls.outbound_request` and `calls.bookings`. The CLI exposes `calls prepare`, `calls outboundRequest` and `calls bookings`. MCP includes `get_outbound_call_request` and `get_call_bookings` and adds `delete_campaign`, bringing MCP to 97 tools.

MCP 0.5.0 exposes 97 tools, including call-result reads and voice campaign deletion. The 19 approved Knowledge tools remain; no direct calendar-booking or knowledge-publication tool is implied.

## Keep safety and coverage explicit

Node and Python automatically retry eligible GET reads only. Mutations are not automatically retried, including after network loss or a malformed response. The SDK’s behaviour does not make an application-level retry loop safe.

Google Calendar connection/settings and in-place number credential updates are included in these clients. Sensitive credential operations use private input and safe result projections. Compatibility account model, voice and storage routes are outside the supported public client inventory; use the dashboard for new setup.

| Failure | Decision |
| --- | --- |
| Installed method missing | Check the minimum client version; use documented HTTP rather than inventing a method. |
| Unknown call launch | Read the saved UUID and call ID; do not allocate a replacement automatically. |
| SMS `do_not_contact` | Stop without resending; retain older 400 handling as well as current 409. |
| Booking result incomplete | Keep its actual state instead of reporting zero bookings. |
