## Copy the right connection details

1. Sign in as the **Owner** and open **API Keys**.
2. Check the displayed **API base URL** is `https://api.nixflex.com`.
3. Choose **Copy full key** beside **Your key**.
4. Store it in the private credential field or secret store of the application you are connecting.
5. Use the relevant [AI tools setup guide](/ai-tools/overview) or give your developer the [authentication guide](/authentication).

The masked text is not the full credential. Do not paste the copied value into agent instructions, website code, public repositories, screenshots or a chat. Invite teammates with their own login instead of sharing the key.

## Check activity and limits

**Last used** describes the latest retained API request. The usage card shows today or the last seven days in UTC, errors and the busiest endpoints. Dashboard background polling is not counted as customer API activity.

The **Limits** card shows the concurrent-call limit and the peak this month. Use **Request increase** if the business needs a higher limit. Do not assume a fixed limit applies to every organisation.

The separate organisation signing secret verifies incoming webhook messages in your application. API-key rotation does not rotate that signing secret. Keep both values private; see [webhook verification](/advanced/webhooks).

## Rotate the key

1. Inventory the applications and integrations that use the current key.
2. Prepare their private configuration so you can update them promptly.
3. Choose **Rotate**, read the confirmation and choose **Rotate key**.
4. After confirmed success, copy the new full key from the result and update those applications.
5. Check a read-only connection and review activity before resuming work.

The old key stops at once. A lost response is not proof that rotation failed: reload API Keys to read the current key before considering another rotation. Do not repeatedly rotate to diagnose a connection problem.

Removing a teammate does not rotate a copied organisation key. Review credential access separately from team membership.
