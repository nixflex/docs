Nixflex is an **AI voice platform for building real-time AI phone agents**. You connect your Twilio number, give the agent a prompt, and your phone agent is live. Inbound and outbound calls, SMS, transfers, bookings, post-call analysis, and batch campaigns - all behind one API.

Built for developers embedding voice agents into SaaS apps - and for businesses that want a phone agent without the plumbing.

## Your first agent

Create an AI phone agent with a single API call:

```bash
curl -X POST "https://api.nixflex.com/v1/agents" \
  -H "Authorization: Bearer nxf_xxx:nxfs_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Front desk",
    "system_prompt": "You are the friendly receptionist for Bella Hair Studio. Greet callers, answer questions, and book appointments."
  }'
```

Then attach a phone number, and the agent answers calls and texts on it. See the [quickstart](/quickstart) for the full flow.

## How it works

A call moves through the engine like this:

1. **Caller dials your Twilio number** (or you trigger an outbound call via API).
2. **Twilio streams audio** to Nixflex over WebSocket.
3. **Speech-to-text** converts what the caller says into text in real time.
4. **The agent reasons** over the conversation and decides what to say or do next.
5. **Text-to-speech** turns the reply into natural voice and streams it back to the caller.
6. **After the call ends**, Nixflex runs post-call analysis (summary, sentiment, custom data extraction) and fires your webhook.

You configure the agent's behaviour with a system prompt and a handful of settings. Everything else - audio handling, interruption detection, language matching, voicemail filtering - is handled by the engine.
