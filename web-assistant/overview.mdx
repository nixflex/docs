title: "Web agent settings: configure website chat and voice"
description: "Read and update Nixflex website settings with revisions, configure chat and voice switches and keep public visitor actions separate from phone capabilities."
---

Manage the saved website configuration for a number. Install the widget through the dashboard-generated snippet, then use the API for supported settings.

Using the dashboard? See [the business guide](/guides/voice-widget).

## Prerequisites

Keep the account credential in `NIXFLEX_API_KEY` on your server. Examples copied from the reviewed kit candidates need Node/CLI 0.10.0 or Python 0.3.0, which are not yet published. Use cURL until the matching release is available. Set all identifiers and the API host for the intended account and environment. Choose an owned number. Browser visitors must never receive the account credential.

## 1. Read the current revision

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.nixflex.com/v1/agent-web/%2B12025550123" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';

const c = new Nixflex({
  apiKey: process.env.NIXFLEX_API_KEY,
  baseUrl: 'https://api.nixflex.com',
  maxRetries: 0,
});
const result = await c.webAgent.get("+12025550123");
```

```python Python
import os
from nixflex import Nixflex

with Nixflex(
    api_key=os.environ["NIXFLEX_API_KEY"],
    base_url="https://api.nixflex.com",
    max_retries=0,
) as c:
    result = c.web_agent.get('+12025550123')
```

```powershell CLI (PowerShell)
nixflex web-agent get '+12025550123' --json --base-url "https://api.nixflex.com"
```

</CodeGroup>

## 2. Prepare focused settings

Keep `revision` as the returned decimal string. Use the endpoint’s allowed `settings` fields only. Website instructions are independent from telephone and SMS prompts. The website prompt is limited to 16,000 characters.

## 3. Save with concurrency protection

PATCH `/v1/agent-web/{number}` with the observed revision and intended settings. On `widget_settings_changed`, reread and review the concurrent changes before saving. Do not silently overwrite another editor’s choices.

## 4. Check effective permissions

Website voice needs the Web agent enabled and its voice switch on. Knowledge has separate website-chat and website-voice channels. `web_functions_enabled` defaults off and applies to all enabled custom functions on that number; each must be safe for public visitors. Built-in phone booking, SMS, transfers, keypad and menu navigation remain unavailable.

## 5. Install and inspect

Copy the current Install snippet from the dashboard. If installation is not ready, resolve that environment configuration first. Test contact collection and microphone access on the installed site, then inspect the website inbox. Visitor-supplied details are unverified.

## Example response

GET returns a safe settings projection and revision. A successful save returns the new state; do not fabricate a permanent browser token or script URL from the account API credential.

## Errors and limits

| Condition | Handling |
| --- | --- |
| 409 widget_settings_changed | Reread and merge deliberate changes. |
| Web agent off | Saved voice preference is not effective voice access. |
| Prompt over 16,000 characters | Shorten channel instructions. |
| Install not ready | Resolve configured snippet availability. |
| Visitor identity present | Treat as self-reported, not verified account access. |
