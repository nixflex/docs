The Web Assistant is an embeddable widget that puts a floating **Call + Chat** launcher on any website. Visitors can call your AI phone number, or chat in text with the same agent. It is a single `<script>` tag - no build step, no dependencies.

<Note>
  Everything about the widget's look and behaviour is controlled by `data-*` attributes on the script tag. The design lives in the snippet, not in the number - so any number with an agent can power any design.
</Note>

## Quick start

<Steps>
  <Step title="Copy the snippet">
    Grab the embed code from your dashboard (Web Assistant tab), or use the example below.
  </Step>
  <Step title="Set your number">
    Put one of your numbers (with an agent attached) in `data-number`.
  </Step>
  <Step title="Paste it before the closing body tag">
    Drop the script just before `</body>` on any page. The launcher appears in the corner.
  </Step>
</Steps>

```html
<script
  src="https://nixflex.com/button.js"
  data-number="+441234567890"
  data-design="1"
  data-color="#25D366"
  data-name="Acme Coffee">
</script>
```

## How it works

- **Call** is a `tel:` link that dials `data-number` - it opens the phone dialer (shows "Call now" on mobile). No browser audio is used.
- **Chat** sends the visitor's message to the widget endpoint and shows the reply in the panel.

The widget is fully inbound and stateless - the browser sends the number and the conversation so far, and the endpoint returns the next reply.

## Attributes

| Attribute | Required | Default | Description |
|---|---|---|---|
| `data-number` | Yes | - | The phone number (with an agent attached) the widget calls and chats with. |
| `data-design` | No | `1` | Which of the 10 preset designs to use (`1`-`10`). |
| `data-color` | No | `#25D366` | Accent colour (hex) for the launcher and buttons. |
| `data-name` | No | agent name | The name shown on the widget. |
| `data-position` | No | `right` | Corner for the launcher: `right` or `left`. |
| `data-icon` | No | design default | Preset launcher icon. |
| `data-greeting` | No | design default | Greeting bubble - see below. |
| `data-chips` | No | design default | Quick-reply buttons for chat, separated by `\|` (e.g. `Book appointment\|Opening hours\|Prices`). |
| `data-api` | No | Nixflex endpoint | Advanced - override the chat endpoint URL. Leave as default. |

## Greeting bubble

`data-greeting` controls the small speech bubble next to the launcher:

- `data-greeting="true"` (or `on`, `yes`, `1`) - show the default greeting ("Need help? Call or chat with us").
- `data-greeting="false"` (or `off`, `no`, `0`) - hide it.
- `data-greeting="Book your table today"` - show that exact custom text.
- If you omit it, designs 9 and 10 show the greeting by default; designs 1-8 do not.

The greeting is visual only - it does not start a chat or cost anything.

## The chat endpoint

The widget's chat calls:

```
POST https://api.nixflex.com/v1/widget/message
Content-Type: application/json

{ "number": "+441234567890", "history": [ ... ] }
```

It always responds with `200` and one of:

```json
{ "ok": true, "reply": "We are open Mon to Fri, 8:30am to 5:30pm." }
```

```json
{ "ok": false, "reason": "server_error" }
```

So the widget never shows a hard error to a visitor. This endpoint is public and needs no API key.

<Note>
  **CORS:** the chat endpoint allows requests from any origin, so the widget works on any customer website with no domain whitelisting.
</Note>

## Offering the widget to your users

If you run a platform and want to give the widget to your own end-users (each on their own website), you do not rebuild the designs - they already exist in `button.js`. You just choose which design each user gets and supply their number. Three ways:

<CardGroup cols={3}>
  <Card title="One design for all" icon="1">
    Hard-code a single `data-design` and only swap `data-number` per user. Simplest.
  </Card>
  <Card title="Let users pick" icon="2">
    Show a small design picker in your own app; write the chosen `data-design` into each user's snippet. Recommended.
  </Card>
  <Card title="Fully custom" icon="3">
    Build your own widget front-end and call `POST /v1/widget/message` directly with the user's number. Total control.
  </Card>
</CardGroup>

## Notes

- **Cost:** a chat message uses AI text usage; a call uses voice minutes (billed like any call). The greeting bubble is free.
- **One widget per page** is recommended.
- The widget script is served from `https://nixflex.com/button.js` and is safe to cache.
