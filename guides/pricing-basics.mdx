## Separate the costs and records

| Cost or record | What it means |
| --- | --- |
| Nixflex usage | Work charged under the applicable service path and account pricing |
| Telephone transport | Separate charges from the business telephone connection |
| Message segments | Text length and encoding can affect external message charges |
| Your own model or voice | Separate connection charges; fallback can change the Nixflex path used |
| Customer storage | Your bucket's storage and access charges |
| Usage counters | Useful totals, but not a complete invoice or charge ledger |

## Shared account, different roles

An organisation shares work and balance. Owner and Admin can use Billing; Member does not see Nixflex money amounts. Sharing an API key is not a way to create a restricted Member view.

## Acceptance is not a billing conclusion

A call can be queued, ringing, connected, transferred or awaiting finalisation. A message can be accepted without being delivered. Do not infer that every rejected-looking browser result is free or that every accepted action has finished. Read the actual operation and payment state.

Website replies can use the shared balance; an external model connection does not automatically make website chat free. Call capacity is also a configured account limit, not an unlimited entitlement inferred from a positive balance.

When reviewing a period, use the same date range and time zone for each report. A payment document, an activity entry and a call-cost total answer different questions. Keep pending items visible until their result is confirmed, and investigate differences using the original operation rather than creating another payment.

## Read the result

| What you see | What it means | What to do |
| --- | --- | --- |
| Different totals | The records may use different purposes, periods or time zones. | Match the reporting choices and inspect the original work. |
| A pending cost | The amount is not final. | Review it after processing instead of treating it as zero. |
| An uncertain payment | You do not yet know the payment outcome. | Check Billing before making another payment. |
