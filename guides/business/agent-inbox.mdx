Use the SMS or Web agent inbox to review customer conversations for a selected business number. Each inbox helps you find unread messages and keep older threads out of the main list without deleting them.

## Before you start

- Sign in with an organisation login that can read shared work.
- Use an Owner or Admin login to change a thread’s saved state.
- Choose a dashboard-managed number with test conversations.

## Steps

### 1. Choose the channel and number

Open **SMS agent** or **Web agent**, then select the number. Check the number before reviewing a conversation: each number has its own inbox, even when several numbers share an agent.

### 2. Find the conversation

Use the search, period and unread filters to narrow the list. Open the thread you need. Load older messages when available. A missing thread can reflect the current filter, number selection or retention state.

<Note>Screenshot placeholder: **agent-inbox-filters** — Agent inbox, unread filter and period selected with two test threads. Use staging test data.</Note>

### 3. Read the messages

Check the customer’s message, the agent’s reply and any delivery information. Website contact details are supplied by the visitor and are not verified identity. A saved conversation is evidence of messages, not proof that a booking or delivery succeeded.

### 4. Archive an older thread

Use **Archive** on a conversation you want out of the main list. Read the confirmation and save. Archiving does not erase messages, stop automatic replies or change your retention settings.

<Note>Screenshot placeholder: **agent-inbox-archive** — Archive conversation, confirmation open for a test thread. Use staging test data.</Note>

### 5. Review archived updates

Open the archived list to find older conversations or restore one. Check the archived-new indicator when new messages arrive. If another window changes the thread while you work, refresh before making another change.

## What happens next

Your main list is easier to review while archived conversations remain available within their retention policy. For follow-up, use your normal customer contact process; this inbox does not include a manual reply composer.

## Common questions

### Does unread mean nobody saw the message?

It reflects the saved inbox read state, not proof of what every team member has seen.

### Will a visitor always keep the same identity?

No. A different browser, cleared storage or blocked storage can create a new visitor identity.

### Does the call retention choice control all messages?

SMS and website messages have their own retention handling. Check the applicable policy rather than assuming every channel uses the same period.

### Can Members change the inbox?

Members can read shared work. Changes to saved shared state require Owner or Admin access.
