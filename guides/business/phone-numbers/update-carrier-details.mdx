<div className="nxf-important">

**The important part**

- The new carrier account must contain the exact number. This is not a carrier switch.
- Credential replacement can change routing and may require fresh verification or a test call.
- Do not delete and reimport a number to recover an uncertain update.
- If asked to finish a pending save, use exactly the same private details. Other unknown outcomes need checking or support first.

</div>

## Before you start

Have Owner or Admin access, the selected number’s current carrier and authorised replacement details. Confirm that exact number belongs to the new carrier account. Enter secrets only in the private dashboard fields.

## Complete the task

<Steps>

<Step title="Open the existing number">

Go to **Phone Numbers → Provider → Update carrier details**. Read the selected number carefully. Avoid making several routing changes at once.

</Step>

<Step title="Enter the replacement details">

Use the fields for the number’s current carrier. Stored secrets are not shown. Do not paste them into agent instructions, chat, a support message or a shared document.

</Step>

<Step title="Submit once and check the result">

Wait for the confirmation. If the result is pending or unknown, read the current number state and the specific guidance shown before doing anything else. A lost browser reply does not establish that no routing changed.

</Step>

<Step title="Complete a stated follow-up">

Follow any fresh verification or test-call request. If Nixflex explicitly permits completion of a pending save, keep the same replacement details. For an unknown carrier outcome, contact support before another attempt.

</Step>

<Step title="Check the channels you use">

Confirm the intended agent remains attached, then test incoming calls and any outgoing or SMS feature you use. Check the number’s switches, integrations and retained history.

</Step>

</Steps>

## Read the result

| What you see | What it means | What to do |
| --- | --- | --- |
| Update confirmed | The existing number has the saved replacement connection. | Complete any requested verification and test the intended channels. |
| Pending save | The operation needs the stated completion step. | Use the same private details only when the dashboard asks you to finish it. |
| Carrier outcome unknown | Routing may have changed without a confirmed response. | Contact support before retrying. |
| Number does not match | The replacement account cannot be used for that exact number. | Check account ownership and the number; do not switch carriers through this action. |
