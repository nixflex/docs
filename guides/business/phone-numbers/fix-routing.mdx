<div className="nxf-important">

**The important part**

- A number move keeps its own settings and integrations; inherited voice and knowledge follow the destination agent.
- Channel switches do not write instructions or connect calendars.
- A missing number in a dashboard list may be managed through code.
- Do not remove and reimport to clear a pending or unknown routing result.

</div>

## Before you start

Have the affected number, an example call or message and the intended destination agent. Use Owner or Admin access to save changes. Confirm the telephone number is active for the calls or texts you expect.

## Complete the task

<Steps>

<Step title="Read the current assignment">

Open **Phone Numbers** and select the number. Confirm its attached agent and connection state. If the number is absent, check whether it was added through code instead of the dashboard.

</Step>

<Step title="Check the channel">

For a phone call, check the appropriate inbound or outbound switch. For texts, check SMS auto-reply and SMS instructions. Website voice needs both Web agent and website voice enabled. A switch alone does not supply instructions.

</Step>

<Step title="Check inherited and number-owned settings">

Review the attached agent’s voice and knowledge, then the number’s calendar and other integrations. Moving between agents can change inherited behaviour while leaving the number’s existing calendar in place.

</Step>

<Step title="Move only when needed">

Choose **Move number**, select the existing number and intended active agent, then confirm. If the number is busy, let current work finish. If a save is unconfirmed, inspect the current assignment before trying again.

</Step>

<Step title="Test the repaired path">

Test one incoming call and each outgoing or text feature you use. Ask a branch-specific question and verify any booking or message result at its destination. Keep the affected call time and redacted error for support if the problem continues.

</Step>

</Steps>

## Read the result

| What you see | What it means | What to do |
| --- | --- | --- |
| Correct assignment, wrong answer | The routing may be right but the instructions or facts wrong. | Review the intended channel and attached agent’s knowledge. |
| Move refused as busy | Live work or another number operation prevents the move. | Wait, then read the current state. |
| Save not confirmed | The routing outcome is uncertain. | Inspect the number before repeating a change. |
| Channel unavailable | A required switch, instruction or telephone capability may be missing. | Check that channel’s setup and run a controlled test. |
