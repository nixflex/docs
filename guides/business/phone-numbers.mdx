Connect a number you own to the agent that should answer it. The number stays in your own telephone account. In Nixflex, each number belongs to one agent at a time and keeps its own channel switches and integrations.

## Before you start

- Use an Owner or Admin login.
- Have an active number in full international format and its connection details.
- Create the agent that will answer it.

## Steps

### 1. Open Phone Numbers

Choose **Phone Numbers** and select **Import number**. Confirm you are working with the intended business line. Importing changes its call routing, so arrange a suitable handover from any existing answering service.

### 2. Complete the connection

Enter the number and the connection fields shown for its setup. Keep credentials private. The number must already be active for the intended calls or texts; importing does not buy a number or enable destinations in your telephone account.

### 3. Choose the agent

Select the agent and complete the import. Wait for the result. If the request is still pending or its result is unknown, inspect the number’s state before trying again. Do not assume a lost response means no routing changed.

### 4. Check its switches

Review inbound, outbound, SMS auto-reply, Web agent, website voice, website custom functions and Live Monitor. Website voice also needs Web agent on. Enabling a channel does not write its instructions or connect its integrations.

### 5. Move it when needed

Choose **Move number**, select the number and the new agent, and confirm the change. A busy number cannot move until its current work finishes. Number settings, integrations and history stay with the number; inherited voice and knowledge follow the new agent.

## What happens next

Test an incoming call and any outgoing or text feature you intend to use. Check the attached agent and knowledge after a move, especially when branches have different facts.

## Common questions

### Do I keep ownership?

Yes. Number rental and telephone charges stay with your telephone account.

### Does removing it cancel the rental?

No. Removing the connection in Nixflex is separate from releasing the number in your telephone account. Cleanup can remain pending.

### Why is a number absent from a dashboard list?

Some dashboard screens show only numbers added there. Numbers managed through code remain managed through code.
