Give your phone agent clear actions for the moments a conversation needs more than an answer. Settings enable the action; instructions explain when to use it. Knowledge adds business facts but does not enable new actions.

## Before you start

- Use an Owner or Admin login and a connected test number.
- Prepare the receiving team number and any approved text or voicemail wording.

## Steps

### 1. Choose one action to configure

Open the agent’s call-action settings. Start with the action your customers need most, such as transferring to reception or texting a useful link. Check whether changing the agent affects other attached numbers.

### 2. Set the destination or message

For transfers, choose the transfer style and real receiving number. A warm transfer can provide a short briefing. For voicemail, enable **Leave a Voicemail Message** and save the approved wording. Avoid customer-specific facts in a shared template.

### 3. Check the matching switches

Enable **In-Call SMS** for texts during phone calls. Post-call SMS has its own setting and template. Voicemail handling depends on how the number was added; a number managed through code uses its own voicemail settings.

### 4. Write the handling rule

Say when the action should happen and what to do if it cannot complete. For example, ask before texting a link and offer to take a message if a person cannot be reached. A greeting should not claim an action has already happened.

### 5. Test the actual outcome

Call from an owned test phone and trigger the action. Check the receiving phone, text message or voicemail recording. Review Call History afterwards. Repeat with an unanswered destination or unavailable service so the fallback is clear.

## What happens next

Keep the action configuration and written instructions together. Review changes when moving a number to another agent, because the new agent’s inherited settings can change behaviour.

## Common questions

### Does a transfer always connect?

No. Test answered and unanswered paths, and keep a fallback for your team.

### Does voicemail detection always leave my message?

No. An earlier answering-machine decision can end the call before a message is spoken.

### Are these actions available on the website?

Built-in phone transfer, SMS, calendar and keypad actions are not website actions.

### Will turning off recording remove old audio?

No. Recording settings affect new work and have their own number overrides and retention rules.
