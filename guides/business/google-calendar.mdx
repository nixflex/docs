Connect the calendar that should handle appointments for one business number. Each number has its own connection and booking settings, even when several numbers share an agent.

## Before you start

- Use an Owner or Admin login; Members can view the connection.
- Have an agent assigned to the number and access to a calendar you can edit.
- Use one booking connection per number. Disconnect Cal.com first if switching to Google Calendar.

## Steps

### 1. Select the number

Open **Integrations** and choose the intended agent and phone number. Check the selection before changing a connection, especially if you run several branches.

### 2. Connect the calendar

Open **Google Calendar**, choose **Connect**, sign in to the intended Google account and approve calendar access. Return to Nixflex and check the account shown. Keep your Google password out of agent instructions.

<Note>Screenshot placeholder: **google-calendar-connected** — Integrations Google Calendar, connected account or event details for selected number. Use staging test data.</Note>

### 3. Set booking hours

Check the calendar, time zone, opening hours and appointment length. Choose the weekly hours you actually accept bookings, marking closed days as closed. Appointment lengths are 15, 30, 45 or 60 minutes. A day's closing time must follow its opening time; an overnight interval is not supported. Do not assume calendar events import your business opening hours.

### 4. Choose caller invitations

Set **Email the caller a Google invite** and save. It starts on, including for an existing connection unless you have turned it off. Wait for the saved state before treating the change as complete. With it on, Google is asked to email the caller an invitation, update or cancellation. With it off, the booking can still be saved without that email request. The switch does not add an owner notification or enable text messages.

<Note>Screenshot placeholder: **google-calendar-settings** — Google Calendar settings, time zone, opening hours, appointment length and Email the caller a Google invite shown; save confirmed. Use staging test data.</Note>

### 5. Test the result

Call from your test phone. Confirm the name read back to you, then confirm the email after it is spelled back. Check the appointment in the selected calendar. Try an unavailable time, a correction, a move and a cancellation. Check invite behaviour separately from whether the event exists.

## Understand the connection status

| Status | What to do |
| --- | --- |
| **Connected** | The connection check succeeded. Still test the booking rules. |
| **Not set up** | Choose **Connect** to set up this number. |
| **Reconnect needed** | Choose **Reconnect**, sign in and approve access again. Saved booking settings are kept. |
| **Could not check** | The check could not finish. Retry before relying on the calendar; this is not proof it disconnected. |

## Common questions

### What happens when I disconnect?

Choose **Disconnect** on this number's card and wait for confirmation. This removes its calendar access in Nixflex without deleting existing appointments. It does not disconnect your other numbers. An action already sent to Google may finish, so check the calendar if a call was booking at that moment.

### Has the caller definitely received the invitation?

No. Google controls email delivery. The agent can say Google will email an invite when that request is confirmed; it cannot promise arrival in the inbox. Check spam and the address if needed. An email-domain check does not prove that the mailbox exists.

### Does this send a text or enable website booking?

Texting needs the separate **In-Call SMS** setting and a confirmed send result. Built-in website calendar actions are unavailable.
