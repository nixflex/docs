<div className="nxf-important">

**The important part**

- Connected reports loading; it does not prove an actual chat or voice conversation worked.
- Website chat and voice have separate knowledge switches on the attached agent.
- A visitor’s contact card is not verified identity, and browser changes can create a new visitor.
- Built-in phone booking, SMS, transfer and keypad actions are unavailable on the website.

## Before you start

Use the test site where the current generated snippet is installed. Know which business number and agent its setup uses. Owner or Admin access is needed to change settings; permitted team members can read shared conversations.

## Complete the task

<Steps>

<Step title="Confirm the installed setup">

Open **Web agent** and check its selected number. Follow **Install** for the current snippet; an older embed may not gain every new visitor or installation feature. If installation is not ready, use the design preview until it is available.

</Step>

<Step title="Test a text conversation">

Open the website in a browser, complete any required contact fields and ask a known question. Then ask something the saved facts do not answer. Check the website instructions and website-chat knowledge switch if the answer is wrong.

</Step>

<Step title="Test voice separately">

Check Web agent and website voice are enabled, then start a browser voice conversation and allow microphone access. Review the website-voice knowledge switch separately from website chat. Do not infer voice readiness from a successful text reply.

</Step>

<Step title="Read the saved conversation">

In **Web agent**, select the same number and use the inbox filters to find the conversation. Check the visitor’s message and agent reply. A missing thread can reflect number selection, filters, browser identity or retention.

</Step>

<Step title="Organise and follow up">

Archive older conversations when appropriate; archive changes the list, not answering or retention. Review archived-new activity. Use your normal customer follow-up process because the inbox has no manual reply composer.

</Step>

</Steps>

## Read the result

| What you see | What it means | What to do |
| --- | --- | --- |
| Connected | The widget reported loading. | Test a complete conversation. |
| Text works, voice does not | Voice has additional switches and microphone requirements. | Check them and test voice separately. |
| New visitor record | The browser may not have the previous saved identity. | Review the conversation and supplied details without assuming identity. |
| Thread not visible | The current number, filters or retention may exclude it. | Check those choices and the archived list. |
| Wrong factual answer | The website instructions or enabled knowledge need review. | Correct the source and repeat the focused test. |
