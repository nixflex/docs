Give your agent reliable business facts to use in conversations. Keep rules and the facts needed on almost every call in its main instructions; put detailed menus, policies and exceptions in **Knowledge base**. Knowledge belongs to the agent. Every attached phone number shares it.

## Before you start

- Use an Owner or Admin login to make changes; Members can read.
- Choose an agent and prepare current business information.

## Steps

### 1. Choose your agent

Open **Knowledge base** and select the agent. Choose **Add knowledge**, or **Edit knowledge** then **Add more** if it already has topics. Different branch answers need separate agents.

<Note>Screenshot placeholder: **knowledge-choose** — Knowledge base, empty agent selected; Paste text, Upload file and My website visible. Use staging test data.</Note>

### 2. Add a source

Choose **Paste text**, **Upload file** or **My website**. For a website, select the pages to read. Files can be clean text, PDF with selectable text or DOCX. Wait for the size check, then add. Existing live knowledge stays available during preparation.

### 3. Review the topics

Read each proposed topic. Correct its title or text, save the edit, then approve the topics you want live. **Check this** pieces start unticked and need individual approval. Leaving a replacement unticked keeps its previous live version.

<Note>Screenshot placeholder: **knowledge-review** — Knowledge review, one normal topic and one unticked Check this topic. Use staging test data.</Note>

### 4. Test real questions

Open **Test** and ask questions customers use. Check the answer and the topics supplied below it. Test checks knowledge only; it makes no call, text or booking. Use a separate call test to check the full agent. Reopening Test starts fresh.

<Note>Screenshot placeholder: **knowledge-test** — Knowledge Test, answer with supplied topics and an unanswered question. Use staging test data.</Note>

### 5. Keep it current

Use **Edit knowledge** to edit or delete topics. A live edit hides the old answer while the update is prepared. Deleting a topic keeps a refresh of that source from bringing it back. Deleting its last live topic also removes the source and its retained original. An explicit new addition of the same information is separate.

In **Settings**, choose where knowledge is used or refresh saved website pages with **I updated my website**. **Download a copy** creates a current plain-text file of live topic titles, text and settings. **Download for developers** creates the fuller JSON copy. Neither includes original uploaded files. Prepared downloads expire after one hour; click again for a current copy. **Delete knowledge** removes the whole base after confirmation.

<Note>Screenshot placeholder: **knowledge-settings** — Knowledge settings, channel switches and Your saved knowledge expanded. Use staging test data.</Note>

## What happens next

Small knowledge is supplied whole; larger knowledge is searched for relevant pieces. Inbound calls start enabled. Outbound calls and campaigns, website voice, website chat and SMS each need their knowledge switch enabled.

## Common questions

### What are automatic keyterms?

Open the agent's **Keyterms** field. **From your knowledge** shows automatically chosen words as chips, with **+N more** for the rest. They come from live knowledge and are ordered by importance. This is in the agent settings, not a new knowledge-page switch.

You can also add up to **20** words or phrases of your own. Each can be at most **50 characters**, and the whole list must fit the displayed size limit. If it is too large, shorten or remove terms before saving. Your words take priority over competing automatic hints and use a separate allowance. Members can view the chips but cannot edit.

<Note>Screenshot placeholder: **knowledge-keyterms** — Agent → Keyterms, manual words, From your knowledge chips and expanded +N more list; no model or supplier names visible. Use staging test data.</Note>

These words help recognition; they do not guarantee correct hearing or pronunciation. Existing older lists can remain during unrelated edits, but a changed list must meet the current limits.

### How much can I add?

Each file can be 10 MiB; each source can hold 20,000 tokens and an agent’s saved knowledge 100,000. A token is a small piece of text, not a word. Topics allow 800 tokens; a base allows 50 sources and 1,000 topics. Follow the on-screen counter.

### Does my website update itself?

No. Choose saved pages to read again and review the changes. Download a copy gives titles, text and settings; it does not return the original uploaded files.
