Choose how long call data is kept and understand the separate steps for downloads and account closure. A saved retention choice controls eligibility for cleanup. Required processing can delay deletion, and files you copied elsewhere remain your responsibility.

## Before you start

- Use Owner or Admin access for shared settings; only the Owner can close the organisation.
- Decide what data your business needs and where you keep separate copies.

## Steps

### 1. Review the account default

Open **Settings** and review the call-data retention default. New agents inherit it. Changing that default does not rewrite the choices already saved on existing agents.

### 2. Check each agent

Open an agent and review **Keep call data for**. Choices include 90, 30, 7 or 1 day, and deletion after each call. Zero-day cleanup waits for required final work; it does not interrupt a live conversation.

### 3. Download available data

In **Settings → Data and privacy**, use the data download control. Keep the resulting file private. It contains supported account records, not secrets or the original recording files. Download recordings separately from Call History and payment documents from Billing.

### 4. Review other copies

Check your own recording bucket, downloaded files and connected tools. Nixflex’s automatic retention does not remove your own bucket files. Caller memory, website contact cards and message retention are separate from the call setting.

### 5. Choose the right leaving action

Use **Leave organisation** if you are an Admin or Member leaving the team. Only the Owner can use **Delete account** to request closure. Read the confirmation carefully and complete any fresh sign-in checks. Closure locks the organisation while cleanup is tracked.

## What happens next

Review the displayed status until work is confirmed. Pending cleanup is not completed erasure. Required billing and trial-protection records can remain, and personal logins survive organisation closure.

## Common questions

### Does leaving delete shared work?

No. It removes your membership; the organisation keeps its work and balance.

### Does disabling caller memory erase saved details?

No. Stopping future memory use is separate from deleting existing records.

### Can I close the organisation using a shared key?

No. Closure requires the Owner’s personal dashboard login.

### Are all messages kept for the call period?

No. Check the channel-specific retention policy; the call setting is not a universal retention control.
