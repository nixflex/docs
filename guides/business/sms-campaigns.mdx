Send a one-time text to a reviewed customer list and follow the result for each recipient. The campaign sends the message; the number’s SMS agent handles replies when auto-reply is enabled. Prepare both before starting.

## Before you start

- Use an Owner or Admin login and an active number that can send texts.
- Prepare your recipient list, permission records and the information needed for each message.

## Steps

<Steps>

<Step title="Create an SMS campaign">

<span id="1-create-an-sms-campaign" />

Open the SMS campaign area under **Outbound**, start a new campaign and choose the agent and sending number. Give it a name that explains its purpose, such as Appointment reminders.

</Step>

<Step title="Write and preview the text">

<span id="2-write-and-preview-the-text" />

Write a short message and add any recipient details. Review the actual text for each person, not only the template. A missing detail can block sending. Segment counts are estimates; characters and languages affect message length.

</Step>

<Step title="Review recipients and timing">

<span id="3-review-recipients-and-timing" />

Paste or upload recipients. Check duplicates, invalid numbers, contact restrictions and each recipient’s local sending hours. Choose the date, days and window. Any change to recipient input requires a fresh permission review.

</Step>

<Step title="Prepare replies and launch">

<span id="4-prepare-replies-and-launch" />

Set up the sending number’s SMS agent with the offer or reminder details. Confirm permission for the reviewed recipients and launch once. Include a clear way to opt out where appropriate. Existing opt-outs remain blocked.

</Step>

<Step title="Check delivery">

<span id="5-check-delivery" />

Open the campaign to review results. Accepted or sent is not the same as delivered. An unknown result needs checking before another send. Cancel stops future sends; messages already handed off cannot be recalled.

</Step>

</Steps>

## What happens next

Incoming replies appear in the number’s SMS conversations. Auto-reply uses its own instructions and enabled knowledge. It does not learn the campaign wording just because the campaign sent it.

## Read the campaign result

| Result | What it means | What to do |
| --- | --- | --- |
| Held recipient | A required recipient check has not passed. | Read its reason and correct the input or wait. |
| Accepted or sent | The message has progressed through sending. | Wait for delivery information; do not mark it delivered yet. |
| Delivered | A delivery result was reported. | Review any customer reply separately in the SMS inbox. |
| Failed | Sending or delivery did not complete successfully. | Read the reason before deciding on a new contact attempt. |
| Unknown | The final outcome is not confirmed. | Check the saved campaign and message state before resending. |

## Common questions

<AccordionGroup>

<Accordion title="Can I remove a STOP opt-out?">

The business cannot remove a person’s locked opt-out. Contact support for a genuine correction request.

</Accordion>

<Accordion title="Does Resume resend delivered texts?">

No. It continues eligible unsent work.

</Accordion>

<Accordion title="Is sending free?">

Message transport is billed through your telephone account. Keep texts concise and check your current rates.

</Accordion>

<Accordion title="What should I check before removing a campaign?" id="can-i-delete-an-active-campaign">

Review the current dashboard confirmation before removing a campaign. Messages already handed off cannot be recalled; use the delivery records to check what happened.

</Accordion>

<Accordion title="What if a removal result is unclear?" id="why-is-deletion-still-waiting-after-sending-stops">

Check the current campaign state and the message shown by the dashboard. If the result is unclear, contact support before repeating a destructive action.

</Accordion>

</AccordionGroup>
