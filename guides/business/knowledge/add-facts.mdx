## Set it up

<Steps>

<Step title="Open the agent’s knowledge">

In **Knowledge base**, select the agent. Choose **Add knowledge**, or **Edit knowledge** then **Add more**.

</Step>

<Step title="Choose the source">

Use **Paste text**, **Upload file** or **My website**. Files can be clean text, PDF with selectable text or DOCX. For a website, choose the pages to read; finding pages does not add all of them.

</Step>

<Step title="Wait for the size check">

Check the on-screen counter before adding. Each source allows 20,000 tokens; an agent’s saved knowledge allows 100,000. A token is a small piece of text, not a word. The base also allows 50 sources and 1,000 topics; each topic allows 800 tokens.

</Step>

<Step title="Review and approve topics">

Read the title and full text of each proposed topic. Correct mistakes and save edits before approval. **Check this** topics start unticked and are excluded from **Select all**; review and approve each one separately.

</Step>

<Step title="Check the live answers">

Wait for publication to finish, then open **Test**. Ask a normal question and one about a condition or exception. [Test and fix answers](/guides/business/knowledge/test-and-fix) explains what the result can prove.

</Step>

</Steps>

## What the review means

On a phone, swipe the table sideways if you cannot see every column.

| Status or result | What it means | What to do |
| --- | --- | --- |
| **Size check in progress** | The source has not finished being measured. | Wait for the exact count; adding stays blocked until the source fits. |
| **Preparing topics** | The source is being turned into topics. | Let the work finish. Progress shows completed stages, not time remaining. |
| **Check this** | The topic needs individual review. | Read the reason and approve only facts you want the agent to use. |
| **Unsaved edits** | Your changes have not been saved. | Save your changes before approving the selected topics. |

## Common questions

<AccordionGroup>

<Accordion title="What happens when I edit a live topic?">

The old answer is hidden while the update is prepared. Wait for the saved result and test the changed answer.

</Accordion>

<Accordion title="Will a deleted topic come back on a website refresh?">

Deleting a topic prevents a refresh of that source from bringing it back. Deleting its last live topic also removes the source and its retained original. Explicitly adding the same information again is a new addition.

</Accordion>

<Accordion title="Why was my file refused?">

Check the stated reason. Password-protected, damaged or image-only PDFs cannot be read as ordinary text. Use a clean supported file or paste the relevant business text.

</Accordion>

<Accordion title="Do warnings find every unsafe instruction?">

No. Review the whole topic yourself. Keep passwords, payment credentials and instructions copied from an untrusted page out of your business facts.

</Accordion>

</AccordionGroup>
