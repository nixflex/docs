<div className="nxf-important">

**The important part**

- **Test makes no call, text or booking.** It checks knowledge without the full agent instructions.
- The topics shown were **supplied** to the answer. That is not proof every fact was used correctly.
- Opening Test starts fresh. Use a separate call to check instructions, speech and actions together.
- A missing answer can mean a missing fact, a poor match or a loading problem. Read the result before changing facts.

</div>

## Check and improve it

<Steps>

<Step title="Open Test">

Choose the agent in **Knowledge base** and open **Test**. You need at least one live topic. Reopening Test starts a fresh conversation.

</Step>

<Step title="Ask a real question">

Use normal customer wording. Try a price, a condition, a follow-up and something the business does not offer. Compare each answer with the facts you approved.

</Step>

<Step title="Read the supplied topics">

Open the topics below the answer. If a fact is wrong or missing, edit it or add an answer you have checked. Saving an edit from a cited topic returns you to that test conversation.

</Step>

<Step title="Try the correction again">

Wait for the update to finish. Start a new test and ask the original question plus a different wording. A live edit hides the old answer while the change is prepared.

</Step>

<Step title="Make a separate call">

Use your own test phone to check the complete agent. Confirm the intended knowledge channel is enabled. Review the transcript and any real booking or message result separately.

</Step>

</Steps>

## What the result means

On a phone, swipe the table sideways if you cannot see every column.

| Status or result | What it means | What to do |
| --- | --- | --- |
| **Knowledge is still loading — try again** | The knowledge could not be loaded in time. | Try again after loading finishes; this is not proof that your facts are absent. |
| **No suitable answer** | The test did not produce a suitable fact-based answer. | Check the saved fact, the channel and the question wording. Add missing information only when you know the answer. |
| **The topic is no longer available** | The cited topic is no longer current or accessible. | It may have been deleted or changed. Review the current live topics. |
| **Knowledge available in a call** | Topics were supplied for that call. | Read the conversation to see whether the answer was right. |

## Common questions

<AccordionGroup>

<Accordion title="What do Strict and Normal mean?">

In **Settings**, Strict needs a closer match. Normal allows more similar wording. Check both ordinary questions and misleading near-matches before choosing what fits your business.

</Accordion>

<Accordion title="What should the agent say when it does not know?">

Set a clear not-found sentence in **Settings**, such as “I don’t have that information right now.” Do not fill missing facts with guesses.

</Accordion>

<Accordion title="Does the missed-question list show every mistake?">

No. It is a review signal from recorded customer turns, not a complete accuracy score. **Add answer** lets you supply a checked fact; Nixflex does not invent your business answer.

</Accordion>

<Accordion title="Why does Test work but an outgoing call does not?">

Check the agent attached to the number and enable its outgoing-call knowledge switch. Incoming knowledge starts on; outgoing calls and campaigns, website voice, website chat and SMS need their own enabled channel.

</Accordion>

</AccordionGroup>
