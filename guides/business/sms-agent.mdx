Let your agent answer customer texts from your business number. SMS has its own instructions and switch. Changing the phone-call prompt does not change text replies, so prepare the texting experience separately.

<div className="nxf-important">

**The important part**

- Save SMS-specific instructions. The phone-call prompt does not control text replies.
- Enable SMS knowledge on the attached agent for the facts you want texts to use.
- Prepare the number’s SMS instructions for a campaign; sending a campaign does not teach its offer to the agent.
- Check the calendar for a booking result and the message record for delivery. A reply alone is not confirmation.

</div>

## Before you start

- Use an Owner or Admin login.
- Choose a dashboard-added number that can receive and send SMS.
- Connect a calendar first if you want appointment booking.

## Steps

<Steps>

<Step title="Choose the number">

<span id="1-choose-the-number" />

Open **SMS agent** and select your business number. Check the attached agent. This screen shows dashboard-managed numbers; a number managed through code may need its settings changed there.

</Step>

<Step title="Set up the instructions">

<span id="2-set-up-the-instructions" />

Choose **Set up agent**, or **Edit agent** for an existing setup. Say what customers can ask and when a person should help. Add a language rule such as “Reply in the same language as the customer” or “Reply only in Spanish”. Ask for short replies: long texts can split into several paid parts. State what the agent must not promise and tell it not to guess missing facts.

</Step>

<Step title="Add the right facts">

<span id="3-add-the-right-facts" />

Include the most-used facts in the SMS instructions. For detailed information, add knowledge to the attached agent and enable its SMS knowledge switch. If a campaign will prompt replies, include that campaign’s current offer or purpose.

</Step>

<Step title="Enable replies">

<span id="4-enable-replies" />

Save the instructions and turn on SMS auto-reply for this number. The switch starts off. Connected calendar tools can support booking by text; website chat has different action rules.

</Step>

<Step title="Test a conversation">

<span id="5-test-a-conversation" />

Text the business number from an owned test phone. Ask a known and an unknown question. If booking is enabled, make a test booking and check the actual calendar. Review the saved conversation and correct anything unclear.

</Step>

</Steps>

## What happens next

New eligible messages receive replies using the saved SMS instructions. Review the inbox for failed or unclear conversations. Message delivery and final booking confirmation should be checked in their respective records.

## Review the test result

| Result | What to check | Next step |
| --- | --- | --- |
| Message saved, no automatic reply | Number, SMS instructions and auto-reply switch. | Correct the setup and run one new test. |
| Reply uses the wrong facts | SMS instructions, attached agent and SMS knowledge switch. | Correct the source of the answer. |
| Booking discussed | The actual connected calendar. | Treat the booking as complete only after its confirmed result. |
| Delivery uncertain | The message’s available delivery information. | Check before sending another text. |

## Common questions

<AccordionGroup>

<Accordion title="Can I read messages with replies switched off?">

Incoming messages can still be saved; the switch controls automatic replies.

</Accordion>

<Accordion title="Does archiving stop replies?">

No. Archive changes the inbox view. Use the auto-reply switch to change answering behaviour.

</Accordion>

<Accordion title="Is there a manual reply box?">

The current inbox is for reading and managing conversations; it does not provide a manual reply composer.

</Accordion>

<Accordion title="What does it cost?">

Your telephone account bills message transport. This version does not add an SMS AI-reply fee; check Billing and current pricing for your account.

</Accordion>

</AccordionGroup>
