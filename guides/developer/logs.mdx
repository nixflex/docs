## Keep an application request record

Save the intended account, API host, operation, safe resource identifier and application correlation ID before a write. Retain any returned request or resource IDs privately. For outbound calls, persist the optional `request_id` UUID with the exact input before the first launch.

The dashboard search accepts an exact `req_` request ID or an endpoint substring. Method, HTTP status family and date filters narrow the list. The request row shows time, method, endpoint, status, latency, safe error code and request ID. It does not retrieve full historical request or response bodies.

## Reconcile by operation

| Operation | Reconciliation |
| --- | --- |
| Outbound call with a saved UUID | [Read the original request](/api-reference/calls/get-outbound-request), keep the same account and host, and never allocate a new UUID automatically. |
| Campaign creation or launch | Read the saved campaign and recipients before another launch. |
| Single call or campaign deletion | Check the list; the same-ID DELETE safely resumes its durable request. |
| Recording read | Preserve pending or unavailable state and retry the read with a bound. |
| Booking automation | Validate the signed event or read retained booking results; do not infer success from a transcript. |

## Webhook delivery evidence

Dashboard delivery rows show response status, attempt count and first/last attempt times. A successful HTTP delivery means the destination accepted that attempt; your receiver still needs durable processing and duplicate handling. Verify signatures against the exact raw request body before processing. Use [delivery and recovery](/guides/developer/webhooks/delivery-and-recovery) for the complete receiver workflow.

## Keep logs safe

Record useful codes and IDs without auth headers, signing secrets, signed recording URLs, full transcripts or private payloads. When opening a support case, include the approximate time, safe request ID and error code. Do not resend the original private body unless a secure support process explicitly needs it.
