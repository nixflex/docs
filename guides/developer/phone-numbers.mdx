Read a number’s saved configuration, change only the intended fields and verify the result. Number assignment, channel switches and inherited settings have different rules.

Using the dashboard? See [the business guide](/guides/business/phone-numbers).

## Prerequisites

Keep the full account credential in `NIXFLEX_API_KEY`. Choose an owned active number and agent. URL-encode the number, including its leading plus sign. Examples use placeholder identifiers; replace them with owned values before running.

## 1. Read the number

Node and Python below use their standard HTTP clients. Keep `NIXFLEX_API_KEY` on the server. The CLI examples require a kit version supporting the command; see [release status](/sdks/ecosystem). No example retries a mutation automatically.

<CodeGroup>

```bash cURL
curl --fail-with-body --request GET \
  --url "https://api.nixflex.com/v1/phone-numbers/%2B12025550100" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY"
```

```javascript Node
const response = await fetch('https://api.nixflex.com/v1/phone-numbers/%2B12025550100', {
  method: 'GET',
  headers: { Authorization: `Bearer ${process.env.NIXFLEX_API_KEY}` },
});
const result = await response.json();
if (!response.ok) throw new Error(JSON.stringify(result));
console.log(result);
```

```python Python
import os, json
from urllib.request import Request, urlopen

request = Request(
    'https://api.nixflex.com/v1/phone-numbers/%2B12025550100',
    method='GET',
    headers={'Authorization': 'Bearer ' + os.environ['NIXFLEX_API_KEY']},
)
with urlopen(request, timeout=30) as response:
    print(json.load(response))
```

```powershell CLI (PowerShell)
nixflex numbers get +12025550100 --json --base-url https://api.nixflex.com
```

</CodeGroup>

## 2. Check ownership and channel switches

Read the saved `source`, `agent_id` and channel flags. `source` is assigned by the import route, not a writable permission switch. `web_calls_enabled` is effective only with `web_agent_enabled`; website custom functions require `web_functions_enabled`. Dashboard source filtering does not transfer account ownership.

## 3. Send a focused change

Use `PATCH /v1/phone-numbers/{number}`. For example, `{"sms_reply_enabled":true}` changes the SMS switch; it does not write SMS instructions. Only documented nullable fields accept null. A number’s explicit recording boolean overrides the agent, while its null value inherits.

## 4. Move without re-importing

Use an agent-only PATCH, `{"agent_id":"agent_destination"}`. The destination must be active and owned by the same account. Live calls, replies, campaigns or number operations can produce `number_busy`. Settings, integrations and history remain on the number; inherited agent behaviour and knowledge change.

## 5. Read back and reconcile

GET the number after a confirmed update. On a lost mutation response, read its state before repeating. Removal also has cleanup and uncertainty states; it is not a promise that every telephone routing change finished or that number rental ended.

## Example response

A number GET returns the safe number object, including `phone_number`, `agent_id`, read-only `source` and saved public settings. Credentials are not returned. Use the [GET schema](/api-reference/phone-numbers/get) for its complete shape.

## Errors and limits

| Condition | Handling |
| --- | --- |
| 404 or inaccessible number/agent | Check the owning account and identifiers. |
| 409 `number_busy` | Wait for in-flight work, then read state again. |
| Pending or uncertain routing cleanup | Reconcile the existing number; do not blindly remove and import. |
| Invalid field or type | Correct it; null is not a universal reset. |
| Number list | Use the endpoint’s opt-in cursor paging; returned count is not a total. |
