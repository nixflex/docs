Help callers book appointments during a phone conversation. The calendar connection supplies live availability and booking results. Your instructions explain when to use it, which details to collect and what to do if booking cannot be confirmed.

## Before you start

- Use an Owner or Admin login and an agent with a connected number.
- Have access to the intended Cal.com or Google Calendar account.

## Steps

### 1. Select the number

Open **Integrations** and choose the agent and business number. Calendar setup belongs to that number. Check the selection carefully if you manage several locations or use one agent for multiple numbers.

### 2. Connect the calendar

Open **Cal.com** or **Google Calendar** and complete its connection. For Cal.com, supply the requested account and event details. For Google Calendar, use **Connect Google Calendar** and approve the intended account.

### 3. Describe the booking task

Tell the agent which appointment the caller can book, what information to confirm and what to say if there is no suitable time. Put detailed services and conditions in knowledge. Use your real calendar time zone, without assuming the caller shares it.

### 4. Choose confirmation settings

For a new booking, the agent asks for the name, reads it back and waits for a separate yes. It then asks for the email, spells it back and waits for another yes. Saved email addresses are spelled back too. A correction repeats only that field. The optional final booking confirmation setting controls approval of the action and time; it does not remove these contact checks.

With Google Calendar, review **Email the caller a Google invite** on the number's calendar card. It starts on. Google handles invitations, updates and cancellations; the agent cannot promise inbox delivery. Cal.com handles its own emails. **In-Call SMS** is separate: the agent can say it texted the details only after a matching send is accepted, and acceptance is not proof of handset delivery.

### 5. Test a complete booking

Call from an owned test phone and ask for a slot. Give a name and email, including a deliberate correction, and check that each corrected field gets its own read-back and yes. Confirm the event actually appears in the calendar. Try an unavailable time and a move or cancellation; existing appointment changes need email approval without asking for a new name. Remove the test appointment through your normal calendar process.

## What happens next

Review early bookings against the calendar. A spoken promise or generated summary is not the final booking record. If a booking cannot be confirmed, the agent should offer a clear follow-up instead of inventing a reservation.

## Common questions

### Is a prompt enough to enable booking?

No. The number needs a working calendar connection.

### Does this work in website chat?

Built-in website calendar actions are unavailable. Phone and SMS booking have separate channel rules.

### Can each branch use its own calendar?

Yes, calendars are connected per number. Shared agent knowledge is still shared across those numbers.

### Will every booking send a text?

No. In-Call SMS and message eligibility must allow it; check delivery separately.
