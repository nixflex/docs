List this account’s voice campaigns, newest first. This bounded list has no offset or cursor.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `status` (query) | string | No | Omitted | Optional exact status filter. Unknown values normally return no matches. |
| `limit` (query) | integer | No | `50` | Parsed as an integer; missing, invalid or nonpositive uses 50; capped at 200. Minimum 1. Maximum 200. |

Do not send a request body.

Sort order is created_at descending. There is no tie-break cursor, offset, total or full-history paging contract. Unknown query keys are ignored. Counts describe stored campaign state, not delivery guarantees.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `campaigns` | array of object | Saved value. |
| `campaigns[].campaign_id` | string | Public campaign ID. |
| `campaigns[].agent_id` | string | Owning agent ID. |
| `campaigns[].name` | string or null | Saved campaign label. |
| `campaigns[].from_number` | string or null | International number with + and digits; no spaces. Pattern: `^\+[1-9][0-9]{6,14}$`. |
| `campaigns[].schedule_type` | string | Saved now or schedule mode. |
| `campaigns[].scheduled_date` | string or null | Saved scheduled date. |
| `campaigns[].window_start_minutes` | integer or null | Configured start minute. |
| `campaigns[].window_end_minutes` | integer or null | Configured end minute. |
| `campaigns[].window_days` | array or null | Saved value. |
| `campaigns[].timezone` | string or null | Saved campaign time zone. |
| `campaigns[].source` | string | Saved origin label. |
| `campaigns[].status` | string | Current state; for example scheduled, launching, running, done, failed or cancelled. Treat new states conservatively. |
| `campaigns[].total_count` | integer | Count. Minimum 0. |
| `campaigns[].started_at` | string or null | Saved timestamp, or null. Format: date-time. |
| `campaigns[].completed_at` | string or null | Saved timestamp, or null. Format: date-time. |
| `campaigns[].created_at` | string or null | Saved timestamp, or null. Format: date-time. |

| `campaigns[].failed_count` | integer | Count. Minimum 0. |

## Example request

The examples use staging. Keep `NXF_STAGING_KEY` in your environment; the CLI uses it through `NIXFLEX_API_KEY`. The shell examples use Bash syntax. Tabs labelled **direct HTTP** do not rely on an SDK or CLI method; the reviewed kit has no matching method.

<RequestExample>

```bash cURL
curl --request GET \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/campaigns?limit=1" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node (direct HTTP)
const response = await fetch(`https://nixflex-voice-engine-staging.up.railway.app/v1/campaigns?limit=1`, {
  method: 'GET',
  headers: { Authorization: `Bearer ${process.env.NXF_STAGING_KEY}` },
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const result = await response.json();
console.log('Request completed.');
```

```python Python (direct HTTP)
import os
import json
from urllib.request import Request, urlopen
from urllib.parse import quote

request = Request(
    f"https://nixflex-voice-engine-staging.up.railway.app/v1/campaigns?limit=1",
    method="GET",
    headers={"Authorization": "Bearer " + os.environ["NXF_STAGING_KEY"]},
)
with urlopen(request, timeout=30) as response:
    result = json.load(response)
print("Request completed.")
```

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

## Retry and idempotency

This is a read-only request. Retry transient connection or server failures with bounded backoff; respect Retry-After for 429. Do not retry validation or ownership errors unchanged. A later read can return newer state.
