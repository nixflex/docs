Request the first launch of an owned voice campaign. Ownership, readiness and launch state are checked before dispatch; each recipient still passes current contact checks.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `id` (path) | string | Yes | None | Exact saved campaign_id owned by this account. This operation does not declare a route-level length or character validator. |

Do not send a request body.

No request body is used. This can contact real recipients. A second launch is refused after a campaign has been claimed, including finished runs. A missing or foreign campaign is reported as 400 invalid_request.

Consent, suppression, recipient-local windows and capacity remain normal contact gates. A manual launch is not permission to bypass them. The response counts enqueued jobs, not ringing or completed calls.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `campaign_id` | string | Campaign ID. |
| `status` | string | Running means queue admission, not completed calls. Value: `"running"`. |
| `total_recipients` | integer | Count. Minimum 0. |
| `enqueued` | integer | Jobs accepted by the queue; not proof of dialing. |
| `failed_to_enqueue` | integer | Zero on a confirmed successful launch; uncertain enqueue returns an error. |
| `message` | string | Queue admission explanation. |

## Example request

The examples use staging. Keep `NXF_STAGING_KEY` in your environment; the CLI uses it through `NIXFLEX_API_KEY`. The shell examples use Bash syntax. Set `NXF_CAMPAIGN_ID` to the intended account-owned identifiers or approved recipient before running. Running this example can contact recipients immediately or when scheduled; use only approved test destinations.

<RequestExample>

```bash cURL
curl --request POST \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/calls/batch/$(node -p 'encodeURIComponent(process.env.NXF_CAMPAIGN_ID)')/launch" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';

const client = new Nixflex({
  apiKey: process.env.NXF_STAGING_KEY,
  baseUrl: 'https://nixflex-voice-engine-staging.up.railway.app',
  maxRetries: 0,
});
const result = await client.campaigns.launch(process.env.NXF_CAMPAIGN_ID);
console.log('Request completed.');
```

```python Python
import os
from nixflex import Nixflex

with Nixflex(
    api_key=os.environ["NXF_STAGING_KEY"],
    base_url="https://nixflex-voice-engine-staging.up.railway.app",
    max_retries=0,
) as client:
    result = client.campaigns.launch(os.environ["NXF_CAMPAIGN_ID"])
    print("Request completed.")
```

```bash CLI
NIXFLEX_API_KEY="$NXF_STAGING_KEY" nixflex campaigns launch "$NXF_CAMPAIGN_ID" \
  --base-url "https://nixflex-voice-engine-staging.up.railway.app" --json
```

</RequestExample>

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 400 | [`invalid_request`](/api-reference/errors#invalid_request) | The identifier or request fields are invalid. | Correct the documented fields before resending. |
| 500 | [`campaign_outcome_unknown`](/api-reference/errors#campaign_outcome_unknown) | A campaign save or launch result is uncertain. | Use details.campaign_id to reconcile; safe_to_retry is false. |
| 503 | [`campaigns_paused`](/api-reference/errors#campaigns_paused) | Campaign admission is temporarily paused. | Wait before a deliberate retry; check any saved campaign first. |
| 500 | [`server_error`](/api-reference/errors#server_error) | The result could not be confirmed. | Read the current state before repeating a write. |
| 409 | [`number_disabled`](/api-reference/errors#number_disabled) | Outbound voice is disabled for this number. | Check the saved campaign and number state. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

No idempotency key is documented. A launch claim prevents a second first launch, but it does not make blind HTTP retries safe. After a timeout or uncertain result, read the same campaign before acting. Resume only verified unattempted rows of the current running campaign; create a new campaign only as an intentional new run.
