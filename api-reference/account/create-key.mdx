## Authentication

This endpoint is unauthenticated. Do not send an existing API credential. Signup is limited to three requests per hour per IP address. Send `Content-Type: application/json`.

## Request fields

Send a JSON object.

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `name` | string or null | No | `null` | Optional account label. Omitted or empty is stored as null; no route-level text length limit is declared. |
| `email` | string or null | No | `null` | Optional contact label. This route does not verify ownership or validate email format. Omitted or empty becomes null. |

Send a JSON object. Unknown fields are not a supported way to configure an account. Signup is limited to three requests per hour per address. Existing application keys belong to their existing account; use rotation to replace a secret.

## Response fields

`201 Created` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `message` | string | Save the returned credential securely; the secret is returned only by creation or rotation. |
| `key_id` | string | Stable API account identifier. |
| `key_secret` | string | Sensitive secret. Never log, share or commit it. |

## Example request

This creates a separate API-only account. Run it only as an intentional signup. The examples use staging and need no existing credential. SDK and CLI examples require Node/CLI 0.11.0 or later or Python 0.4.0 or later. Account signup is intentionally absent from MCP; do not emulate it with another tool. Set `NXF_SECRET_RESPONSE_FILE` to a new file in a private, access-restricted location before using cURL or CLI. Save the returned secret in your secret store; do not log or commit the response.

<RequestExample>

```bash cURL
curl --request POST \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/keys" \
  --header "Content-Type: application/json" \
  --data '{"name":"Example API account"}' \
  --output "$NXF_SECRET_RESPONSE_FILE"
```

```javascript Node
import Nixflex from 'nixflex';
const baseUrl = 'https://nixflex-voice-engine-staging.up.railway.app';
const result = await Nixflex.createKey({name:"Example API account"}, baseUrl);
// Handle result privately; do not log secrets or call content.
```

```python Python
import os, json
from pathlib import Path
from nixflex import Nixflex
base_url = "https://nixflex-voice-engine-staging.up.railway.app"
result = Nixflex.create_key(name="Example API account", base_url=base_url)
# AsyncNixflex supports the same calls with await (and async with).
```

```bash CLI
NIXFLEX_API_KEY="$NXF_STAGING_KEY" nixflex keys create --name "Example API account" --confirm --base-url https://nixflex-voice-engine-staging.up.railway.app --json > "$NXF_SECRET_RESPONSE_FILE"
```

</RequestExample>

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 400 | [`invalid_json`](/api-reference/errors#invalid_json) | The request body is not valid JSON. | Fix the JSON syntax before sending it. |
| 413 | [`payload_too_large`](/api-reference/errors#payload_too_large) | The JSON body exceeds the request parser limit. | Send a smaller JSON body. |
| 429 | [`key_creation_rate_limited`](/api-reference/errors#key_creation_rate_limited) | The address has reached the signup limit of three requests per hour. | Wait for Retry-After; do not create extra accounts to work around a refusal. |
| 500 | [`server_error`](/api-reference/errors#server_error) | The account result could not be confirmed. | Do not repeat signup automatically; ask support to reconcile the named request. |

</div>

## Retry and idempotency

No idempotency key is documented. Each successful signup creates a different account. A lost response can leave a created account whose secret you did not receive. Do not automatically repeat signup; reconcile through support. There is no public API-only account deletion endpoint.
