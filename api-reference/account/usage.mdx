title: "Get usage"
description: "GET /v1/usage"

---

Returns your account's usage totals and current limits: calls, minutes, spend, your rate and concurrency limits, and this month's peak concurrency.

## Request

```bash
curl https://api.nixflex.com/v1/usage \
  -H "Authorization: Bearer KEY_ID:KEY_SECRET"
```

Or with the [SDK](https://www.npmjs.com/package/nixflex):

```javascript
const usage = await client.usage.get();
```

This endpoint takes no parameters. For usage over a specific date range, list calls with [List calls](/api-reference/calls/list) and aggregate by `started_at`.

## Response

`200 OK`:

```json
{
  "plan": "pay_as_you_go",
  "total_calls": 891,
  "total_minutes": 551.54,
  "total_cost": 45.9664,
  "rate_limit_per_minute": 300,
  "max_concurrent": 40,
  "peak_concurrent_this_month": 6,
  "rejected_at_cap_this_month": 0
}
```

| Field | Type | Notes |
|---|---|---|
| `plan` | string | Your billing plan, e.g. `pay_as_you_go`. |
| `total_calls` | number | Calls on this key, all time. |
| `total_minutes` | number | Fractional minutes - `551.54` is 551 minutes 32 seconds. |
| `total_cost` | number | Nixflex charges in USD, all time. Does not include carrier costs, which Twilio or Telnyx bill you directly. |
| `rate_limit_per_minute` | number | API requests allowed per minute on this key. See [Rate limits](/reference/rate-limits). |
| `max_concurrent` | number | Simultaneous calls allowed on your account. |
| `peak_concurrent_this_month` | number | The highest number of simultaneous calls reached this month. Use it to see how close you run to the cap. |
| `rejected_at_cap_this_month` | number | Calls refused this month because the concurrency cap was already reached. Anything above zero means you are losing calls - contact us to raise the cap. |

## Use cases

- Show total spend and volume in your own admin panel
- Watch `peak_concurrent_this_month` against `max_concurrent` to plan capacity before a campaign
- Alert on `rejected_at_cap_this_month` moving above zero - the clearest signal you need a higher cap
- Reconcile Nixflex charges against your own records

<Note>
  Your credit balance and invoices are in the dashboard under **Billing**. This endpoint reports usage and limits, not billing state.
</Note>
