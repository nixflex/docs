Remove one non-Owner member from this organisation. Shared work and the shared API key remain. A successful response does not always confirm live disconnection.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` for server-side organisation API-key authority, or a verified personal dashboard Bearer session. The shared API key has Owner authority for these methods; keep it server-side. A personal session is checked against current membership and MFA. The Owner may remove non-Owners. An Admin may remove Members only. Members cannot use this route. The environment must have organisations enabled; otherwise these routes return 404. Personal invitation acceptance, leaving and ownership transfer are separate dashboard flows and are not API-key methods.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `id` (path) | string | Yes | None | UUID identifier. Format: uuid. |

Do not send a request body.

A 200 response has live_disconnect_pending=false. A 202 response means the membership change committed but live disconnection remains unconfirmed. Neither status promises AI hand-back or ends an ongoing human call. Recheck access and current membership before retrying.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `user_id` | string | UUID identifier. Format: uuid. |
| `state` | string | Resulting membership state. Value: `"removed"`. |
| `live_disconnect_pending` | boolean | True when the membership change committed but live disconnection is unconfirmed. |

## Example request

The examples use staging. Keep `NXF_STAGING_KEY` in your environment; the CLI uses it through `NIXFLEX_API_KEY`. The shell examples use Bash syntax. Kit tabs use the reviewed Node/CLI 0.10.0 and Python 0.3.0 unpublished candidates. Method presence does not promise complete field coverage. Set `NXF_MEMBER_ID` privately to the intended owned identifiers or integration values before running.

<RequestExample>

```bash cURL
curl --request DELETE \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/organisation/members/$(node -p 'encodeURIComponent(process.env.NXF_MEMBER_ID)')" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';

const client = new Nixflex({
  apiKey: process.env.NXF_STAGING_KEY,
  baseUrl: 'https://nixflex-voice-engine-staging.up.railway.app',
  maxRetries: 0,
});
const result = await client.organisation.removeMember(process.env.NXF_MEMBER_ID);
// Handle the result privately; do not log credentials or destination URLs.
```

```python Python
import os
from nixflex import Nixflex

with Nixflex(

    max_retries=0,

    result = client.organisation.remove_member(os.environ["NXF_MEMBER_ID"])
    # Handle the result privately; never log credentials or destination URLs.
```

```bash CLI
NIXFLEX_API_KEY="$NXF_STAGING_KEY" nixflex organisation remove "$NXF_MEMBER_ID" --confirm \

```

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 404 | [`not_found`](/api-reference/errors#not_found) | Organisation routes are not enabled in this environment. | Check deployment availability; do not retry unchanged. |
| 503 | [`organisation_unavailable`](/api-reference/errors#organisation_unavailable) | The organisation action could not be confirmed. | Refresh the current state before trying again. |
| 403 | [`permission_denied`](/api-reference/errors#permission_denied) | The current personal role does not allow this action. | Use an authorised personal session; do not share the organisation key. |
| 403 | [`membership_revoked`](/api-reference/errors#membership_revoked) | The personal membership has ended. | Sign in again or contact the Owner. |
| 401 | [`invalid_token`](/api-reference/errors#invalid_token) | The personal session is invalid or expired. | Sign in with your own login again. |
| 503 | [`auth_unavailable`](/api-reference/errors#auth_unavailable) | The personal session could not be verified. | Retry the read later; reconcile uncertain changes. |
| 400 | [`invalid_id`](/api-reference/errors#invalid_id) | The path ID is not a UUID. | Correct the request before retrying. |
| 409 | [`membership_unavailable`](/api-reference/errors#membership_unavailable) | The target is not an active member. | Correct the request before retrying. |
| 409 | [`last_owner`](/api-reference/errors#last_owner) | The Owner cannot be removed or demoted through this route. | Use the personal ownership-transfer flow. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

No idempotency key is accepted. After a timeout or 503, read the current team or organisation state before repeating the action. Invitation creation and resend can send email and consume quota; never replay them blindly.
