---
title: "Update agent"
description: "PUT /v1/agents/:id — Batch 1 draft"
api: "PUT https://api.nixflex.com/v1/agents/{agent_id}"
---

Draft. Send only the fields you want to change. The [contract](/api-reference/agents/contract)
lists fields, limits and clear values. PUT additionally accepts
`call_retention_days: 90 | 30 | 7 | 1 | 0`; 0 means delete after each call.

```json
{ "temperature": 0, "incall_sms_enabled": false, "voicemail_leave_enabled": false }
```

Empty or unknown-only updates return `400 empty_agent_update`, never a fake success.
A mixed request such as `{"temperature":0,"temperatur":1}` saves temperature
and returns the updated safe agent plus:

```json
{
  "warnings": [{
    "code": "unknown_fields",
    "fields": ["temperatur"],
    "message": "These fields were not saved."
  }]
}
```

Invalid known fields reject the whole request before a write.
Server-generated IDs/owner/timestamps are not writable; they follow the unknown-key rule.
Omitted fields are retained. Enabling voicemail or clearing its message checks the
merged saved setting: enabled requires non-blank text.

## Errors

| HTTP/code | Meaning |
|---|---|
| 400 invalid_agent_field | Wrong type, range or structured extraction shape |
| 400 empty_agent_update | No supported field supplied |
| 400 prompt_too_long | Prompt exceeds 16000 characters |
| 400 voicemail_message_required | Enabled voicemail needs text |
| 400 deprecated_field | Real agent-level carrier credentials are refused |
| 404 not_found | No affected owned agent, including a row removed during the request |
| 503 agent_store_unavailable | Database problem; not a false 404 |
| 503 catalog_unavailable | Catalog could not be checked |

`recording_source`, `remember_callers` and retention retain their dedicated error codes.
GET the agent before repeating an uncertain write.
