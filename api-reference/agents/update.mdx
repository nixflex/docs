---
title: "Update agent"
description: "PUT /v1/agents/:id"
api: "PUT https://api.nixflex.com/v1/agents/{agent_id}"
---

Updates an agent's configuration. Only include fields you want to change — omitted fields keep their current values.

## Request

```bash
curl -X PUT https://api.nixflex.com/v1/agents/agent_125207e452f8714a \
  -H "Authorization: Bearer KEY_ID:KEY_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "welcome_message": "Hi, Acme Dental, how may I help you today?",
    "response_length": "short"
  }'
```

## Body parameters

Any field from [Create agent](/api-reference/agents/create) can be updated. Pass only the fields you want to change.

### Field behaviour worth knowing

| Field | Behaviour on update |
|---|---|
| `speaking_rate` | Clamped to the supported range rather than rejected, so `9` is stored as the maximum. Send `null` to clear it and go back to normal speed - `null` is not the same as `1`. See [Voices](/concepts/voices). |
| `dtmf_enabled` | Three-state. `true` and `false` are explicit; `null` means **not set**, which lets a phone number's own setting decide. |
| `system_prompt` | Maximum 16000 characters, about 4000 tokens. Over that the whole update is rejected with `prompt_too_long`. |
| `voice_speed` | Accepted and saved, but **nothing reads it**. Use `speaking_rate`. |
| `func_send_sms`, `func_cold_transfer` | Accepted and saved, but **not enforced** - the agent texts and transfers regardless. Control them in your prompt. See [Create agent](/api-reference/agents/create). |

<Note>
  Fields not listed in [Create agent](/api-reference/agents/create) are ignored rather
  than rejected. If a setting is not taking effect, check the field name against that
  page first - an unrecognised name returns `200` and changes nothing.
</Note>

## Response

`200 OK` — returns the updated agent object.

## Behaviour

- **Active calls are unaffected.** Updating an agent while a call is in progress doesn't change behaviour mid-call. New calls use the new config.
- **`agent_id` and `api_key_id` are immutable.** Trying to change them is ignored.
- **No partial validation.** If you submit an invalid value for any field, the whole update fails.

## Errors

| Code | Cause |
|---|---|
| `agent_not_found` | ID doesn't exist or isn't yours |
| `prompt_too_long` | New `system_prompt` exceeds 16000 characters |
| `invalid_voice_id` | Voice not supported |
