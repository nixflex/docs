Get an agent in the authenticated account.

## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `id` (path) | string | Yes |  |

Do not send a request body.

Fetch an owned agent using its `agent_id`.
Returns the same reviewed safe settings as create/update/list, including response delay,
STT controls, timezone, SMS settings, extraction, voicemail and retention.
No carrier auth token or unreviewed future column is returned.

GET still returns an owned soft-disabled agent; `is_active` is false.

| HTTP/code | Meaning |
|---|---|
| 200 | Owned agent and its settings |
| 404 not_found | Missing or belongs to another account (same response) |
| 503 agent_store_unavailable | Storage could not be checked; do not interpret as missing |

### Read automatic knowledge terms

Automatic knowledge terms are read-only. They come from valid, unsuppressed live pieces, keep source spelling, and are ranked by importance, essential identity, repeated support and stable tie-breaks. Generic terms are filtered. The default limit is 80 per agent; platform configuration can choose 0–100. Customer terms take priority and stay first on calls; duplicates and weaker automatic terms are removed to fit the call limits. The returned list is not a promise that every term will be sent on a call. Read [automatic keyterms](/api-reference/knowledge/get-agents-target-knowledge-keyterms). The optional `knowledge_keyterms` array appears when knowledge is enabled and filters against the saved customer terms.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status | Meaning |
| --- | --- |
| 400 | Invalid request - missing or malformed parameters. |
| 401 | Authentication failed - bad or missing API key. |
| 404 | Not found on your account. |
| 429 | Rate limit exceeded. Honour the Retry-After header. |
| 500 | Server error. |
| 503 | Agent storage or catalog unavailable; check before retrying a write. |



## Retry and idempotency

Use bounded retries only for temporary read failures. Keep the same filters while paging. See [retry rules](/api-reference/retries).
