---
title: "List agents"
description: "GET /v1/agents — Batch 1 draft"
api: "GET https://api.nixflex.com/v1/agents"
---

Draft. Returns a bare array of your active agents, newest first.
Each item has the same safe settings projection as create/update/get.
Disabled agents are excluded from this list but can still be fetched by owned ID.
Carrier auth tokens and unreviewed future columns are never returned.

Pagination is unchanged: `limit` defaults to 100 and is capped at 200;
`offset` defaults to 0. Ordering remains `created_at` descending.
Batch 1 does not redesign pagination or add status/search filters.

Database failures return `503 agent_store_unavailable`, not an empty successful list.
