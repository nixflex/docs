Owned agents; active by default. Optional status/search. Stable created_at DESC, agent_id DESC ordering. Bare array. Strict bounds: invalid queries return 400 invalid_agent_list.

## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `limit` (query) | integer | No | Strict decimal integer; no signs, fractions, leading zeros or repeated values. Invalid values return 400 invalid_agent_list; not clamped. Maximum 200 Minimum 1 Default: 100 |
| `offset` (query) | integer | No | Strict decimal integer. Pages are not a snapshot during concurrent writes. Maximum 1000000 Minimum 0 Default: 0 |
| `status` (query) | string | No | Allowed: active, disabled, all Default: "active" |
| `search` (query) | string | No | Case-insensitive literal name/agent_id substring. Trim outer whitespace; empty means no search. Control characters forbidden. No wildcard or regex syntax. At most 200 characters |

Do not send a request body.

Returns a bare array of your agents; active only unless status is supplied.
Each item has the same safe settings projection as create/update/get.
Disabled agents can be listed with status=disabled or status=all, or fetched by owned ID.
Carrier auth tokens and unreviewed future columns are never returned.

| Parameter | Contract |
|---|---|
| limit | Integer 1..200, default 100 |
| offset | Integer 0..1000000, default 0 |
| status | active (default), disabled, all |
| search | Case-insensitive literal substring of name or agent_id; up to 200 characters, no control characters; leading/trailing whitespace trimmed; empty = no search |

Numbers must be decimal digits without signs, leading zeros (except 0), fractions,
exponents or trailing text. Repeated/array/object values are rejected.
Invalid query values return `400 invalid_agent_list`, not silent clamping/defaults.
Use the documented bounds and encode query values.

Order is `created_at DESC, agent_id DESC`, including tied creation times. Pages are
not a snapshot: concurrent creation, enabling/disabling or edits may shift offsets.
Every filter remains scoped to the authenticated API key. Search cannot change that.
Special characters such as %, _, *, quotes and parentheses are literal, not wildcards.

Example: `GET /v1/agents?status=all&search=Support&limit=50&offset=50`.
URL-encode search values (the kits do this automatically).

Node: `client.agents.list({status:'all',search:'Support',limit:50,offset:50})`.
`client.agents.iter(200)` walks active agents until a short/empty page. Its page size
must be an integer 1..200 (larger sizes throw before HTTP); it does not silently stop
after 200 total agents. At the maximum offset it throws rather than truncate silently.
CLI: `nixflex agents list --status all --search Support --limit 50 --offset 50`.
Python (sync or await): `client.agents.list(status='all', search='Support', limit=50, offset=50)`.
MCP: `list_agents` takes the same four fields; no new tool or confirmation needed.

Database failures return `503 agent_store_unavailable`, not an empty successful list.

### Read automatic knowledge terms

Automatic knowledge terms are read-only. They come from valid, unsuppressed live pieces, keep source spelling, and are ranked by importance, essential identity, repeated support and stable tie-breaks. Generic terms are filtered. The default limit is 80 per agent; platform configuration can choose 0–100. Customer terms take priority and stay first on calls; duplicates and weaker automatic terms are removed to fit the call limits. The returned list is not a promise that every term will be sent on a call. Read [automatic keyterms](/api-reference/knowledge/get-agents-target-knowledge-keyterms). The optional `knowledge_keyterms` array appears when knowledge is enabled and filters against the saved customer terms.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status | Meaning |
| --- | --- |
| 400 | Invalid agent list query. |
| 401 | Invalid or missing API key |
| 404 | Not found on your account. |
| 429 | Rate limit exceeded. Honour the Retry-After header. |
| 500 | Server error. |
| 503 | Agent storage or catalog unavailable; check before retrying a write. |



## Retry and idempotency

Use bounded retries only for temporary read failures. Keep the same filters while paging. See [retry rules](/api-reference/retries).
