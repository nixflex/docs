Cancel future work for an owned SMS campaign. Calls or messages already in progress may finish.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `id` (path) | string | Yes | None | Account-owned campaign identifier. Maximum 100 characters. Minimum 1 characters. Pattern: `^[A-Za-z0-9_-]+$`. |

Do not send a request body.

The body is unused. Cancellation does not recall accepted messages, undo completed calls, or remove contact records. A repeated cancellation can return already_terminal.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `campaign_id` | string | Campaign ID. |
| `status` | string | Cancelled state. Value: `"cancelled"`. |
| `in_progress_may_finish` | boolean | Already in-progress contact may still finish. Value: `true`. |

## Example request

These examples use the unpublished client candidates: Node/CLI 0.10.0, Python 0.3.0 and MCP 0.4.0. Keep `NXF_STAGING_KEY` private. cURL uses Bash; CLI uses PowerShell and reads the key through `NIXFLEX_API_KEY`. Replace fixture identifiers and reserved example numbers with approved account-owned values. Configure the existing MCP installation for the same staging host and account before using the shown tool arguments. Python shows the synchronous client; `AsyncNixflex` uses the same method with `async with` and `await`. This example changes state. Review the target and payload before running it.

<RequestExample>

```bash cURL
curl --request POST \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/sms/campaigns/campaign_fixture/cancel" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';

const c = new Nixflex({
  apiKey: process.env.NXF_STAGING_KEY,
  baseUrl: 'https://nixflex-voice-engine-staging.up.railway.app',
  maxRetries: 0,
});
const result = await c.sms.campaigns.cancel("campaign_fixture");
```

```python Python
import os
from nixflex import Nixflex

with Nixflex(
    api_key=os.environ["NXF_STAGING_KEY"],
    base_url="https://nixflex-voice-engine-staging.up.railway.app",
    max_retries=0,
) as c:
    result = c.sms.campaigns.cancel('campaign_fixture')
```

```powershell CLI (PowerShell)
$env:NIXFLEX_API_KEY = $env:NXF_STAGING_KEY
nixflex sms campaigns cancel campaign_fixture --confirm --json --base-url "https://nixflex-voice-engine-staging.up.railway.app"
```

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 400 | [`invalid_request`](/api-reference/errors#invalid_request) | The identifier or request fields are invalid. | Correct the documented fields before resending. |
| 404 | [`not_found`](/api-reference/errors#not_found) | No matching object belongs to this account. | Check the account and identifier. |
| 503 | [`feature_paused`](/api-reference/errors#feature_paused) | This control is paused. | Wait for availability; do not work around the refusal. |
| 503 | [`outcome_unknown`](/api-reference/errors#outcome_unknown) | The write result could not be confirmed. | Read current state; do not resend automatically. |
| 409 | [`already_terminal`](/api-reference/errors#already_terminal) | The campaign already reached a terminal state. | Read its final state; no new cancellation is needed. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

No idempotency key is documented. A timeout or 5xx can follow a committed change. Read the current state before deciding whether to submit again; never automatically repeat an uncertain write. A confirmed already_terminal response is a state refusal, not proof that nothing previously ran.
