Sets the details for one caller on one of your numbers. Creates the record if needed. A field left out keeps its value; send null to remove it. last_call and open_item are engine-only and are rejected.

## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | One of your numbers in E.164 format. URL-encode the leading + as %2B. |
| `callerNumber` (path) | string | Yes | The caller's number in E.164 format. URL-encode the leading + as %2B. |

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `name` | string or null | No | Unchanged | Full name - first and last. At most 120 characters |
| `email` | string or null | No | Unchanged | At most 120 characters |
| `phone` | string or null | No | Unchanged | A contact number other than the one they call from. At most 40 characters |
| `location` | string or null | No | Unchanged | Free text - city, area or postal code. At most 120 characters |
| `reference_id` | string or null | No | Unchanged | An account, order or booking reference the caller uses. At most 64 characters |
| `preference` | string or null | No | Unchanged | At most 200 characters |

Sets what your agent knows about one caller on one of your numbers. Creates the record if it does not exist.

See [Caller context](/concepts/caller-context) for how the agent uses these details on a call.

### Body parameters

Send at least one field. A field you leave out keeps its current value; send `null` to remove it.

| Field | Type | Max length | Notes |
|---|---|---|---|
| `name` | string or null | 120 | Full name - first and last. The agent uses it naturally and confirms it before booking. |
| `email` | string or null | 120 | Must be a valid address. Confirmed with the caller before it is used for an action. |
| `phone` | string or null | 40 | A contact number other than the one they call from. |
| `location` | string or null | 120 | Free text - city, area, postal code, whatever suits your market. |
| `reference_id` | string or null | 64 | An account, order or booking reference the caller uses. |
| `preference` | string or null | 200 | A short preference, for example `prefers morning appointments`. |

`last_call` and `open_item` are written by the engine after each call and cannot be set here - sending them returns `engine_only_field`. An unrecognised field name is rejected rather than ignored, so a typo never disappears silently.

### Behaviour

- **Last write wins per field.** If the caller confirms a different email on a call, the engine stores the new one and the next call uses it. Send the field again to set it back.
- **An empty value never erases.** Only an explicit `null` removes a field.
- **One record per number, per caller.** The same person on another of your numbers is a separate record - import them to each number you want them recognised on.
- Takes effect on the caller's next call or text. Calls already in progress are unaffected.

## Response fields

`200` returns the following shape.

| Field | Type | Meaning |
| --- | --- | --- |
| `caller` | object | Always returned. |
| `caller.phone_number` | string | Always returned. |
| `caller.caller_number` | string | Always returned. |
| `caller.context` | object | Only fields with a value are present. |
| `caller.context.name` | string or null | Full name - first and last. At most 120 characters |
| `caller.context.email` | string or null | At most 120 characters |
| `caller.context.phone` | string or null | A contact number other than the one they call from. At most 40 characters |
| `caller.context.location` | string or null | Free text - city, area or postal code. At most 120 characters |
| `caller.context.reference_id` | string or null | An account, order or booking reference the caller uses. At most 64 characters |
| `caller.context.preference` | string or null | At most 200 characters |
| `caller.context.last_call` | string | Engine-written. What the caller wanted on their last call - never what happened. |
| `caller.context.open_item` | string | Engine-written. Something still pending for the caller. |

`context` is the whole record - your fields together with anything the engine has learned.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status | Meaning |
| --- | --- |
| 400 | Invalid request - missing or malformed parameters. |
| 401 | Authentication failed - bad or missing API key. |
| 404 | Not found on your account. |
| 429 | Rate limit exceeded. Honour the Retry-After header. |
| 500 | Server error. |

| Code | Cause |
|---|---|
| `phone_number_not_found` | The number is not on this account |
| `engine_only_field` | `last_call` or `open_item` was sent |
| `unknown_field` | A field name that is not in the table above |
| `invalid_email` | `email` is not a valid address |
| `field_too_long` | A value is over its maximum length |
| `missing_field` | No fields were sent |

## Retry and idempotency

Disable automatic write retries. A lost response leaves the result uncertain; read the affected resource before another deliberate action. No general Idempotency-Key replay guarantee applies. See [retry rules](/api-reference/retries).
