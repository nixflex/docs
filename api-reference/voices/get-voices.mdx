List the voices visible to this account. Compatibility is calculated for the optional agent context; catalog availability can change before a call.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `language` (query) | string | No | Omitted | Supported fixed language code. multi is invalid here; use agent_language for that context. |
| `gender` (query) | string | No | Omitted | Optional gender filter. Allowed: `"male"`, `"female"`, `"unknown"`. |
| `locale` (query) | string | No | Omitted | Ordering preference, not a strict filter. |
| `agent_id` (query) | string | No | Omitted | Optional owned agent whose saved language provides the compatibility context. Ignored when agent_language is supplied. |
| `agent_language` (query) | string | No | Omitted | Optional supported language code or multi for a draft agent. Takes precedence over agent_id. |
| `availability` (query) | string | No | `"active"` | all includes temporarily unavailable/unavailable voices. Any other supplied value follows the active behaviour. |
| `limit` (query) | integer | No | `50` | The handler parses an integer and clamps it to 1–100. Missing, zero or unparseable values use 50. Minimum 1. Maximum 100. |
| `cursor` (query) | string | No | Omitted | Opaque next_cursor from the previous page. Keep the same account and filters. |

Do not send a request body.

Native language matches sort first, then matching locale, display name, and voice key. Compatibility context changes selectable; it does not remove every incompatible voice from the list. Keep filters unchanged while following next_cursor. Stop at null. The server does not return total_in_scope.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `data` | array of object | Visible voices on this page. |
| `data[].voice_key` | string | Stable neutral catalog identifier; use this value when selecting a voice. |
| `data[].displayName` | string | Display label, not an identifier. |
| `data[].gender` | string | Catalog gender label. Allowed: `"male"`, `"female"`, `"unknown"`. |
| `data[].nativeLanguage` | string or null | Native language code, when known. |
| `data[].locale` | string or null | Locale label, when known. |
| `data[].accents` | array of object | Available accent labels. |
| `data[].accents[].language` | string | Accent language. |
| `data[].accents[].locale` | string or null | Accent locale. |
| `data[].accents[].label` | string | Neutral accent label. |
| `data[].languages` | array of string | Languages approved for this voice. |
| `data[].origin` | string | Standard catalog or a connection belonging to this account. Allowed: `"standard"`, `"connected"`. |
| `data[].availability` | string | Current catalog availability. Allowed: `"active"`, `"temporarily_unavailable"`, `"unavailable"`. |
| `data[].selectable` | boolean | Whether a new selection is compatible with the supplied agent context. |
| `data[].incompatibilityReason` | string or null | Reason when not selectable: voice_unavailable, voice_temporarily_unavailable, no_approved_languages, native_language_not_in_multi_set or language_not_approved. These are response values, not HTTP errors. |
| `data[].previewLanguage` | string or null | Preview language, or null when no preview exists. |
| `data[].previewStatus` | string | Preview state; none when no preview is available. |
| `data[].previewUrl` | string or null | Preview URL when present. Null does not imply that the voice is unavailable. |
| `next_cursor` | string or null | Continuation cursor, or null at the end. No total count is returned. |

## Example request

The examples use staging. Keep `NXF_STAGING_KEY` in your environment; the CLI uses it through `NIXFLEX_API_KEY`. The shell examples use Bash syntax. Kit examples use the tested Node/CLI 0.10.0 and Python 0.3.0 candidates; these versions are unpublished.

<RequestExample>

```bash cURL
curl --request GET \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/voices?limit=25&language=en&agent_language=multi" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node
import Nixflex from 'nixflex';
const baseUrl = 'https://nixflex-voice-engine-staging.up.railway.app';
const client = new Nixflex({apiKey:process.env.NXF_STAGING_KEY,baseUrl,maxRetries:0});
const result = await client.voices.list({limit:25,language:"en",agent_language:"multi"});
// Handle result privately; do not log secrets or call content.
```

```python Python
import os, json
from pathlib import Path
from nixflex import Nixflex
base_url = "https://nixflex-voice-engine-staging.up.railway.app"
with Nixflex(os.environ["NXF_STAGING_KEY"], base_url=base_url,max_retries=0) as client:
    result = client.voices.list(limit=25,language="en",agent_language="multi")
# AsyncNixflex supports the same calls with await (and async with).
```

```bash CLI
NIXFLEX_API_KEY="$NXF_STAGING_KEY" nixflex voices list --limit 25 --language en --agent-language multi --base-url https://nixflex-voice-engine-staging.up.railway.app --json
```

</RequestExample>

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 400 | [`invalid_gender`](/api-reference/errors#invalid_gender) | The gender filter is unsupported. | Use male, female or unknown. |
| 400 | [`invalid_language`](/api-reference/errors#invalid_language) | The language filter is invalid or multi. | Use a supported fixed language code. |
| 400 | [`invalid_agent_language`](/api-reference/errors#invalid_agent_language) | The draft agent language is invalid. | Use a supported language code or multi. |
| 400 | [`agent_not_found`](/api-reference/errors#agent_not_found) | The agent context was not found for this account. | Use an owned agent ID or agent_language. |
| 400 | [`invalid_cursor`](/api-reference/errors#invalid_cursor) | The cursor is malformed or belongs to another account/filter. | Restart with the intended filters. |
| 409 | [`cursor_expired`](/api-reference/errors#cursor_expired) | The catalog revision changed. | Restart at the first page and deduplicate by voice_key. |
| 503 | [`catalog_unavailable`](/api-reference/errors#catalog_unavailable) | The catalog is not loaded. | Retry the read after a short wait. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

This is a read-only request. Retry transient connection or server failures with bounded backoff; respect Retry-After for 429. Do not retry validation or ownership errors unchanged. A later read can return newer state.
