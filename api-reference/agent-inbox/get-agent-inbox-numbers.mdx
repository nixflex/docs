List owned numbers available to the inbox and active agent labels. Pending number imports are excluded; both API and dashboard number sources can appear.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `offset` (query) | integer | No | `0` | Skip this many numbers; fixed page size 100. Minimum 0. Maximum 10000. |

Do not send a request body.

Numbers are ordered by phone_number ascending. Increase offset by 100 while has_more is true, up to the offset limit. Agent labels are a separate list capped at 1,000 and have no pagination field here. Requests return Cache-Control: no-store.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `numbers` | array of object | Saved value. |
| `numbers[].phone_number` | string | International number with + and digits; no spaces. Pattern: `^\+[1-9][0-9]{6,14}$`. |
| `numbers[].agent_id` | string or null | Assigned agent ID. |
| `numbers[].source` | string or null | Saved source. |
| `numbers[].sms_prompt` | string or null | SMS instructions. |
| `numbers[].web_prompt` | string or null | Website instructions. |
| `numbers[].sms_reply_enabled` | boolean or null | SMS reply setting. |
| `numbers[].web_agent_enabled` | boolean or null | Web chat setting. |
| `numbers[].web_calls_enabled` | boolean or null | Website voice setting. |
| `agents` | array of object | At most 1,000 active agents, ordered by agent_id. |
| `agents[].agent_id` | string | Active agent ID. |
| `agents[].name` | string or null | Agent label. |
| `has_more` | boolean | True when the number page contains exactly 100 rows; another page may be empty. |

## Example request

These examples use the supplied client candidates: Node/CLI 0.11.0, Python 0.4.0 and MCP 0.5.0. Keep `NXF_STAGING_KEY` private. cURL uses Bash; CLI uses PowerShell and reads the key through `NIXFLEX_API_KEY`. Replace fixture identifiers and reserved example numbers with approved account-owned values. Configure the existing MCP installation for the same staging host and account before using the shown tool arguments. Python shows the synchronous client; `AsyncNixflex` uses the same method with `async with` and `await`.

<RequestExample>

```bash cURL
curl --request GET \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/agent-inbox/numbers?offset=0" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';

const c = new Nixflex({
  apiKey: process.env.NXF_STAGING_KEY,
  baseUrl: 'https://nixflex-voice-engine-staging.up.railway.app',
  maxRetries: 0,
});
const result = await c.inbox.numbers({"offset": 0});
```

```python Python
import os
from nixflex import Nixflex

with Nixflex(
    api_key=os.environ["NXF_STAGING_KEY"],
    base_url="https://nixflex-voice-engine-staging.up.railway.app",
    max_retries=0,
) as c:
    result = c.inbox.numbers(offset=0)
```

```powershell CLI (PowerShell)
$env:NIXFLEX_API_KEY = $env:NXF_STAGING_KEY
nixflex inbox numbers --offset 0 --json --base-url "https://nixflex-voice-engine-staging.up.railway.app"
```

```json MCP
{
  "name": "list_inbox_numbers",
  "arguments": {
    "offset": 0
  }
}
```

</RequestExample>

## Retry and idempotency

This is a read-only request. Retry transient connection or server failures with bounded backoff; respect Retry-After for 429. Do not retry validation or ownership errors unchanged. A later read can return newer state.
