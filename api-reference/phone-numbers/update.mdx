- Read back the number and check its effective agent assignment.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential. Send `Content-Type: application/json`.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | None | Business number. Use E.164 and URL-encode the leading + as %2B. |

Send a JSON object.

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `inbound_enabled` | boolean | No | Unchanged | Saved channel switch. Must be a JSON boolean. Omitted stays unchanged. |
| `outbound_enabled` | boolean | No | Unchanged | Saved channel switch. Must be a JSON boolean. Omitted stays unchanged. |
| `monitor_enabled` | boolean | No | Unchanged | Saved monitor permission; not a live listener control. Must be a JSON boolean. |
| `web_calls_enabled` | boolean | No | Unchanged | Saved channel switch. Must be a JSON boolean. Omitted stays unchanged. |
| `web_agent_enabled` | boolean | No | Unchanged | Saved channel switch. Must be a JSON boolean. Omitted stays unchanged. |
| `web_functions_enabled` | boolean | No | Unchanged | Saved channel switch. Must be a JSON boolean. Omitted stays unchanged. |
| `custom_prompt` | string or null | No | Unchanged | Number prompt override. Null or empty clears to null. Maximum 8000 characters. |
| `voice_id` | string or null | No | Unchanged | Existing voice alias override. Trimmed; null or empty clears to null. No route-level length cap is declared. |
| `sms_reply_enabled` | boolean | No | Unchanged | SMS auto-reply switch. Legacy input also recognises the string true; use JSON booleans. |
| `sms_prompt` | string or null | No | Unchanged | SMS prompt override. Null or empty stores an empty string. Maximum 20000 characters. |
| `web_prompt` | string or null | No | Unchanged | Web prompt override. Null or empty stores an empty string. Maximum 16000 characters. |
| `speaking_rate` | number or null or string | No | Unchanged | Number values are clamped to 0.5–1.5. Null or an empty string clears to inheritance; use 1 for normal speed. |
| `dtmf_enabled` | boolean or null | No | Unchanged | Keypad override. Null or empty clears to inheritance; legacy true strings are accepted. |
| `require_booking_confirmation` | boolean or null | No | Unchanged | Saved confirmation override; null inherits the agent. New voice bookings always need one combined approval, even when false. |
| `record_call` | boolean or null | No | Unchanged | Recording override; null inherits the agent. |
| `recording_source` | string or null | No | Unchanged | provider or nixflex; null or empty inherits the agent. Case and surrounding whitespace are normalised. Allowed: `"provider"`, `"nixflex"`, `null`, `""`. |
| `voicemail_leave_enabled` | boolean or null | No | Unchanged | Number-specific voicemail setting; null is unset. When enabled, the merged message must be nonblank. |
| `voicemail_message` | string or null | No | Unchanged | Number-specific message. Null or empty clears to null. Maximum 2000 characters. |

For a move request, the body is instead exactly one field:

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `agent_id` | string | Yes for a move | None | Trimmed, nonblank target agent ID; at most 200 characters. Do not combine it with settings. |

Omitted settings remain unchanged. The six strict switches below accept only JSON booleans; sms_reply_enabled and older override fields retain their documented legacy coercion. Use canonical snake_case names. A saved web_calls_enabled value is not proof that all effective web-call prerequisites are satisfied.

### Number controls

The seven switches cover inbound, outbound, SMS reply, web agent, web calls, web functions and saved monitor permission. Off switches can prevent new work without ending an existing call. Read the number to confirm saved and effective state.

### Move to another agent

Send only `{ "agent_id": "agent_TARGET" }`. The move preserves number-specific settings and history and does not change carrier routing. New work uses the target agent. A busy number is refused. Repeating the same settled assignment returns changed: false. The move response contains agent_name and changed, while a settings response contains saved settings.

Read web_calls_effective from the number detail endpoint to check effective website access. Saved permission does not start a monitor session. Never delete and re-import a number just to move it between agents.

## Example request

These examples use `https://api.nixflex.com`. Keep `NIXFLEX_API_KEY` in your private process environment. The shell examples use Bash syntax. Kit examples require Node/CLI 0.11.0 or later and Python 0.4.0 or later. Set `NXF_PHONE_NUMBER` to the intended account-owned identifiers or approved recipient before running.

<RequestExample>

```bash cURL
curl --request PATCH \
  --url "https://api.nixflex.com/v1/phone-numbers/$NXF_PHONE_NUMBER" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"sms_reply_enabled":false}'
```

```javascript Node
import Nixflex from 'nixflex';
const baseUrl = 'https://api.nixflex.com';
const client = new Nixflex({apiKey:process.env.NIXFLEX_API_KEY,baseUrl,maxRetries:0});
const result = await client.phoneNumbers.update(process.env.NXF_PHONE_NUMBER, {sms_reply_enabled:false});
// Handle result privately; do not log secrets or call content.
```

```python Python
import os, json
from pathlib import Path
from nixflex import Nixflex
base_url = "https://api.nixflex.com"
with Nixflex(os.environ["NIXFLEX_API_KEY"], base_url=base_url,max_retries=0) as client:
    result = client.phone_numbers.update(os.environ["NXF_PHONE_NUMBER"], sms_reply_enabled=False)
# AsyncNixflex supports the same calls with await (and async with).
```

```bash CLI
nixflex numbers update "$NXF_PHONE_NUMBER" --set sms_reply_enabled=false --base-url https://api.nixflex.com --json
```

</RequestExample>

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

| Status | Code | Meaning | What to do |

| 400 | [`invalid_number_control`](/api-reference/errors#invalid_number_control) | A strict switch is not a JSON boolean or aliases conflict. | Send true or false once for that switch. |
| 400 | [`invalid_agent_move`](/api-reference/errors#invalid_agent_move) | A move contains other settings or an invalid agent ID. | Send only agent_id; update settings separately. |
| 400 | [`invalid_number`](/api-reference/errors#invalid_number) | A move URL does not contain a complete E.164 number. | Correct and URL-encode the number. |
| 400 | [`custom_prompt_too_long`](/api-reference/errors#custom_prompt_too_long) | The number prompt exceeds 8,000 characters. | Shorten it. |
| 400 | [`sms_prompt_too_long`](/api-reference/errors#sms_prompt_too_long) | The SMS prompt exceeds 20,000 characters. | Shorten it. |
| 400 | [`web_prompt_too_long`](/api-reference/errors#web_prompt_too_long) | The web prompt exceeds 16,000 characters. | Shorten it. |
| 400 | [`voicemail_message_too_long`](/api-reference/errors#voicemail_message_too_long) | The voicemail message exceeds 2,000 characters. | Shorten it. |

| 400 | [`invalid_recording_source`](/api-reference/errors#invalid_recording_source) | The recording source value is unsupported. | Use provider, nixflex or null. |

## Retry and idempotency

Never automatically retry PATCH. Read the number after an uncertain settings write or move. Do not change routing to compensate for an unconfirmed move.
