Owned public numbers only; pending imports and internal browser identities are hidden. Without limit/cursor the legacy envelope stays unchanged. count is returned rows, not total. Paged reads order by created_at DESC NULLS LAST, phone_number DESC; live traversal, not a snapshot.

## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `limit` (query) | integer | No | Opts into cursor paging; 1–100. Omitted with a cursor defaults to 50. Maximum 100 Minimum 1 |
| `cursor` (query) | string | No | Opaque next_cursor from the preceding page; keep the same account and filters. At most 1024 characters |
| `agent_id` (query) | string | No | Only numbers assigned to this agent. At most 200 characters |

Do not send a request body.

Returns public numbers owned by your API key. Pending imports and internal
browser-test identities are hidden. Both API-added and dashboard-added numbers
are included. The dashboard Phone numbers page is unchanged.

### Query parameters

| Parameter | Type | Notes |
|---|---|---|
| `agent_id` | string | Optional exact agent filter |
| `provider` | `twilio` or `telnyx` | Optional exact carrier filter |
| `limit` | integer 1–100 | Opt into cursor paging |
| `cursor` | string | Opaque `next_cursor` from the previous page. With cursor alone limit defaults to 50 |

Without pagination parameters the existing `{ phone_numbers, count }` envelope
stays unchanged. The configured database row cap still applies; there is no
guaranteed 1,000-row contract. Use paging to traverse large accounts.
`count` ALWAYS means rows in this response, never the account total.



Paged responses add `next_cursor` (string or null) and `has_more` (boolean).
Keep the account and filters unchanged; pass the cursor unchanged and URL-encoded.
Invalid limit, provider or cursor returns `400 invalid_number_query`.



Numbers are newest first. Paged reads break equal timestamps by phone number
descending and put missing timestamps last. Follow `next_cursor` until null,
even if fewer than `limit` rows arrive. This is a live list, not a snapshot:
new imports appear on a fresh traversal; removed rows can disappear between pages.

Empty lists return 200 with count 0, not 404. The existing Twilio number SID stays
for compatibility. Credentials and internal row/account IDs never appear.
`source` is descriptive api/dashboard (null for unknown legacy origin),
not writable and never a permission. See [Get phone number](/api-reference/phone-numbers/get)
for full saved settings and [seven switches](/api-reference/phone-numbers/switches).

## Example request

Production HTTP examples. Replace the placeholder identifiers with resources owned by the account. Set `NXF_API_KEY` privately; never print it.

<RequestExample>

```bash cURL (Bash)
curl --request GET \
  --url 'https://api.nixflex.com/v1/phone-numbers' \
  --header "Authorization: Bearer $NXF_API_KEY"
```

```javascript Node (HTTP)
const response = await fetch('https://api.nixflex.com/v1/phone-numbers', {
  method: 'GET',
  headers: { Authorization: `Bearer ${process.env.NXF_API_KEY}` },
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const result = await response.json();
// Handle the private result without logging it.
```

```python Python (HTTP)
import os, json

request = Request('https://api.nixflex.com/v1/phone-numbers', method='GET',
    headers={'Authorization': 'Bearer ' + os.environ['NXF_API_KEY']})

    result = json.load(response)
# Handle the private result without logging it.
```

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status | Meaning |
| --- | --- |
| 400 | Invalid phone-number paging or filter query. |
| 401 | Invalid or missing API key |
| 404 | Not found on your account. |
| 429 | Rate limit exceeded. Honour the Retry-After header. |
| 500 | Server error. |



## Retry and idempotency

Use bounded retries only for temporary read failures. Keep the same filters while paging. See [retry rules](/api-reference/retries).
