Preview recipient-local contact windows without sending calls, SMS or campaign work. The result is advisory and expires after one minute; final dispatch checks still apply.

<div className="nxf-facts">
  <div><small>Method</small><strong>POST</strong></div>
  <div><small>Success</small><strong>200</strong></div>
  <div><small>Scope</small><strong>Owning account</strong></div>
</div>

<div className="nxf-important">

**The important part**

- The preview is advice for the supplied recipient location and time.
- It neither sends a message nor reserves a future contact window.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential. Send `Content-Type: application/json`.

## Request fields

Unknown root fields are ignored.

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `agent_id` | string | Yes | None | Owned agent with a configured valid IANA time zone. Pattern: `^[A-Za-z0-9_-]{1,64}$`. |
| `recipients` | array of object | Yes | None | Between one and 20 recipients. Maximum 20 items. Minimum 1 items. |
| `recipients[].phone` | string | Yes | None | Input number used for location estimates. Maximum 32 characters. |
| `recipients[].country` | string | No | Omitted | Optional two-letter country. Maximum 2 characters. |
| `recipients[].timezone` | string | No | Omitted | Optional recipient time zone. Maximum 80 characters. |
| `campaign` | object | No | Omitted | Optional preview assumptions; unknown keys are ignored. |
| `campaign.allow_wider_hours` | boolean | No | `false` | Preview assumption only; does not record permission. |
| `campaign.start` | string | No | Omitted | HH:mm start; provide end too. Pattern: `^(?:[01][0-9]&#124;2[0-3]):[0-5][0-9]$`. |
| `campaign.end` | string | No | Omitted | HH:mm end; must differ from start. Pattern: `^(?:[01][0-9]&#124;2[0-3]):[0-5][0-9]$`. |
| `campaign.days` | array of string | No | Omitted | Optional selected weekdays. Maximum 7 items. Minimum 1 items. Allowed items: `"sun"`, `"mon"`, `"tue"`, `"wed"`, `"thu"`, `"fri"`, `"sat"`. |
| `campaign.scheduled_date` | string | No | Omitted | Valid calendar date in YYYY-MM-DD form. Format: date. |

The campaign preview uses start and end as HH:mm, unlike campaign creation’s minute fields. Omitted period settings use the current policy. Unknown or ambiguous locations, holidays and unverified policy data can hold a row rather than promise a future window. Multiple possible zones must satisfy the applicable checks.

next_allowed is a bounded estimate: computation can stop for budget, horizon or missing policy data. windows describe current recipient-local-date windows, not an unlimited future schedule. allow_wider_hours only changes the preview assumption; it does not save the required campaign confirmation. The example versions and times are illustrative.

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

## Example request

These examples use the supplied client candidates: Node/CLI 0.11.0, Python 0.4.0 and MCP 0.5.0. Keep `NXF_STAGING_KEY` private. cURL uses Bash; CLI uses PowerShell and reads the key through `NIXFLEX_API_KEY`. Replace fixture identifiers and reserved example numbers with approved account-owned values. Configure the existing MCP installation for the same staging host and account before using the shown tool arguments. Python shows the synchronous client; `AsyncNixflex` uses the same method with `async with` and `await`.

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 400 | [`invalid_contact_preview`](/api-reference/errors#invalid_contact_preview) | The preview request has an invalid shape or limit. | Correct agent, recipients and campaign preview fields. |
| 404 | [`not_found`](/api-reference/errors#not_found) | No matching object belongs to this account. | Check the account and identifier. |
| 422 | [`agent_timezone_required`](/api-reference/errors#agent_timezone_required) | The owned agent has no valid configured time zone. | Configure the intended time zone before requesting a preview. |
| 429 | [`contact_preview_busy`](/api-reference/errors#contact_preview_busy) | The preview worker is busy. | Wait and retry with bounded backoff. |
| 503 | [`contact_preview_unavailable`](/api-reference/errors#contact_preview_unavailable) | Policy or preview data could not be confirmed. | Retry later; do not treat failure as permission to contact. |
| 400 | [`invalid_json`](/api-reference/errors#invalid_json) | Invalid JSON body. | Correct JSON syntax. |
| 413 | [`payload_too_large`](/api-reference/errors#payload_too_large) | The request exceeds the JSON body limit. | Send a smaller request. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

This POST is read-only and can be retried with bounded backoff. Its result expires after one minute and is never a send-permission token. Respect 429 and compute a fresh preview when inputs or timing change.
