Clear the saved web calls setting for an owned number. This controls the saved number switch for website voice calls. Reading or changing the switch does not start a call.

<div className="nxf-facts">
  <div><small>Method</small><strong>DELETE</strong></div>
  <div><small>Success</small><strong>200</strong></div>
  <div><small>Scope</small><strong>Owning account</strong></div>
</div>

<div className="nxf-important">

**The important part**

- Clear only the intended target setting; already dispatched work cannot be recalled.
- A saved web-call configuration is not proof a browser session connected.

</div>

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential. When personal dashboard sessions are enabled, Owner and Admin sessions can write these settings; Member sessions can read only. Ownership checks still apply.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | None | Owned E.164 number. URL-encode the leading plus sign. |

Do not send a request body.

The GET response reports the saved number flag, not the full effective website availability. Agent settings and service availability can still prevent a website call. The website Web agent must also be on. Read phone-number details for web_calls_effective; account, agent and billing checks still apply.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `ok` | boolean | Request succeeded. Value: `true`. |
| `phone_number` | string | Owned phone number. |
| `web_calls_enabled` | boolean | Disabled. Value: `false`. |

## Example request

Examples require Node/CLI 0.11.0 or later, Python 0.4.0 or later and MCP 0.5.0 or later. Keep `NIXFLEX_API_KEY` in your private process environment. The cURL example uses Bash. Use approved owned fixtures and keep configuration responses private. Python shows sync usage; AsyncNixflex uses the same method with async with and await. Configure the existing MCP installation for the same account at `https://api.nixflex.com`. Review the target and payload before this write.

<RequestExample>

```bash cURL
curl --request DELETE \
  --url "https://api.nixflex.com/v1/integrations/web-calls/number/%2B12025550123" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';
const c = new Nixflex({apiKey:process.env.NIXFLEX_API_KEY,baseUrl:'https://api.nixflex.com',maxRetries:0});
const result = await c.integrations.delete("web-calls", "+12025550123");
// Keep private responses out of logs and AI conversations.
```

```python Python
import os
from nixflex import Nixflex
with Nixflex(api_key=os.environ["NIXFLEX_API_KEY"], base_url="https://api.nixflex.com", max_retries=0) as c:
    result = c.integrations.delete('web-calls', '+12025550123')
```

```powershell CLI (PowerShell)
nixflex integrations delete web-calls '+12025550123' --confirm --json --base-url "https://api.nixflex.com"
```


</RequestExample>

MCP does not offer this operation because it disconnects an integration used by calls; use the API, Node, CLI or Python.

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 404 | [`not_found`](/api-reference/errors#not_found) | No matching owned resource or saved configuration was found. | Check the identifier and owning account. |
| 500 | [`server_error`](/api-reference/errors#server_error) | The result could not be confirmed. | Read the current state before retrying a write. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the full account credential. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

The operation writes one saved setting and has no idempotency token. Read the current value after an uncertain response. Repeating it can overwrite a newer change, so reconcile before resending.
