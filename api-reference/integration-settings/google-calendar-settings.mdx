Set calendar timezone, weekly hours, slot length and caller invitations for an owned Nixflex number. Omitted settings retain their saved value.

## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | Owned E.164 number. URL-encode the leading +. |

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `timezone` | string | No | Unchanged | IANA timezone. Explicit per-number timezone wins; older settings can inherit the agent timezone. At most 100 characters |
| `hours` | object | No | Unchanged | Replace the entire seven-day map. Omit to retain saved hours. |
| `slot_minutes` | integer | No | Unchanged | Older connections default to 30 minutes. Allowed: 15, 30, 45, 60 |
| `calendar_id` | string | No | Unchanged | Editable calendar ID; primary by default. At most 1024 characters |
| `send_invites` | boolean | No | Unchanged | Defaults to true when not previously stored. Omission on PATCH preserves the setting. Google controls delivery. |

Send one or more fields. Omission preserves each saved value. `hours` replaces the whole map: provide all seven lowercase weekday names, each null or exactly `["HH:MM", "HH:MM"]`. Closing must follow opening on the same day; overnight intervals are refused. Legacy defaults are Monday–Friday 09:00–17:00, 30-minute slots and `primary` calendar.

`send_invites` is a JSON boolean. Existing connections default to true when the value is absent. A string such as `"false"`, null or a number is refused. When enabled, Google is asked to email the caller an invitation, update or cancellation; Google controls delivery. No owner attendee or separate owner email is added. Setting false requests no Google notification. See [booking flow](/actions/booking-confirmation).

## Response fields

`200` returns the following shape.

| Field | Type | Meaning |
| --- | --- | --- |
| `timezone` | string | IANA timezone. Explicit per-number timezone wins; older settings can inherit the agent timezone. At most 100 characters |
| `hours` | object | Replace the entire seven-day map. Omit to retain saved hours. |
| `hours.monday` | alternative shapes | Null when closed; otherwise [opening, closing], with closing strictly after opening on the same day. |
| `hours.tuesday` | alternative shapes | Null when closed; otherwise [opening, closing], with closing strictly after opening on the same day. |
| `hours.wednesday` | alternative shapes | Null when closed; otherwise [opening, closing], with closing strictly after opening on the same day. |
| `hours.thursday` | alternative shapes | Null when closed; otherwise [opening, closing], with closing strictly after opening on the same day. |
| `hours.friday` | alternative shapes | Null when closed; otherwise [opening, closing], with closing strictly after opening on the same day. |
| `hours.saturday` | alternative shapes | Null when closed; otherwise [opening, closing], with closing strictly after opening on the same day. |
| `hours.sunday` | alternative shapes | Null when closed; otherwise [opening, closing], with closing strictly after opening on the same day. |
| `slot_minutes` | integer | Older connections default to 30 minutes. Allowed: 15, 30, 45, 60 |
| `calendar_id` | string | Editable calendar ID; primary by default. At most 1024 characters |
| `send_invites` | boolean | Defaults to true when not previously stored. Omission on PATCH preserves the setting. Google controls delivery. |

The response contains safe settings and `send_invites`; it contains no OAuth credentials.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status | Meaning |
| --- | --- |
| 400 | invalid_settings, invalid_timezone, invalid_hours, invalid_slot_minutes, invalid_calendar_id, invalid_send_invites. Standard error envelope; branch on error.code. |
| 401 | unauthorized. Standard error envelope; branch on error.code. |
| 403 | permission_denied, account_unavailable. Standard error envelope; branch on error.code. |
| 404 | number_not_found. Standard error envelope; branch on error.code. |
| 409 | not_connected, expired_link. Standard error envelope; branch on error.code. |
| 429 | rate_limit_exceeded. Standard error envelope; branch on error.code. |
| 503 | calendar_unavailable. Standard error envelope; branch on error.code. |

`invalid_send_invites` means the value was not a boolean. PATCH requires a connected calendar.

## Retry and idempotency

Disable automatic write retries. A lost response leaves the result uncertain; read the affected resource before another deliberate action. No general Idempotency-Key replay guarantee applies. See [retry rules](/api-reference/retries).
