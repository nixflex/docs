## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | Owned E.164 number. URL-encode the leading +. |

Do not send a request body.

`connected: true` means a saved connection exists. If `needs_reconnect: true`, ask for fresh consent; do not label it ready for booking. Disconnected or absent connections return `connected: false`. GET checks Google access with a bounded refresh. A temporary provider failure returns 503 and must not be displayed as a disconnected account. No credential is returned.

## Response fields

`200` returns the following shape.

| Field | Type | Meaning |
| --- | --- | --- |
| `connected` | boolean | Always returned. |
| `account_email` | string or null | Always returned. |
| `calendar_id` | string | Always returned. |
| `connected_at` | string or null | Always returned. |
| `needs_reconnect` | boolean | Always returned. |
| `send_invites` | boolean | Always returned. |

`send_invites` is always a boolean; an absent saved value reads as true.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status / code | What it means | What to do |
| --- | --- | --- |
| 401 · `unauthorized` | The credential is missing or invalid. | Check the full account credential and API host privately; stop the retry loop. |
| 403 · `permission_denied` | This actor cannot perform the operation. | Resolve the account or role restriction through an authorised person. |
| 403 · `account_unavailable` | The account is unavailable for this operation. | Resolve the account or role restriction through an authorised person. |
| 404 · `number_not_found` | The number is absent or inaccessible to this account. | Check the exact owned identifier and current resource state; do not probe another account. |
| 429 · `rate_limit_exceeded` | The request limit was reached. | Wait at least Retry-After and use a bounded read retry. |
| 503 · `calendar_unavailable` | The calendar operation or status check could not be completed. | Keep the last result unknown and use bounded read retries; do not replace it with empty data. |

Treat 503 as an unknown check result. Do not overwrite the last known connection state.

## Retry and idempotency

Use bounded retries only for temporary read failures. Keep the same filters while paging. See [retry rules](/api-reference/retries).
