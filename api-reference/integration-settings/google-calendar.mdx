## Current booking behavior

A number can use only one booking calendar at a time, including the calendar inherited from its agent. [Set Cal.com](/api-reference/integration-settings/put-integrations-calcom-number-phoneNumber) returns **409 `booking_provider_conflict`** when another calendar is connected. The response identifies it in `error.details.connected_provider`.

Disconnect the existing calendar intentionally before connecting a different one. Do not guess Google Calendar routes or send credentials to an undocumented endpoint.
