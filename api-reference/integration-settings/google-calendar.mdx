## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | Owned E.164 number. URL-encode the leading +. |

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `return_url` | string | Yes | Omitted | HTTPS return URL, or an operator-approved app scheme. No credentials, fragment, whitespace or OAuth-secret query parameters. At most 2048 characters |

Assign an agent first. A number can use one booking provider; a Cal.com connection conflicts with Google Calendar. Open the returned URL in the user's browser to obtain consent. The link expires after ten minutes and can be used once. A saved connection that needs reconnect can request fresh consent; reconnect preserves business settings.

Use HTTPS for `return_url`. Custom app schemes require the service operator to approve ownership and add the scheme for the organisation; there is no public allowlist endpoint. Do not use credentials, fragments, whitespace, backslashes or OAuth-secret query names. The app receives status only, never OAuth codes or tokens.

| Redirect result | Meaning |
| --- | --- |
| `status=connected&phone_number=...` | Connection saved for that number. |
| `status=error&code=access_denied` | Consent was refused. |
| `status=error&code=expired_link` | Link expired or the bound identity/revision changed. Start a new flow. |
| `status=error&code=already_connected` | Existing connection or a booking-provider conflict. Read current state. |
| `status=error&code=google_error` | Google connection could not complete. |

Ordinary return URL query parameters are kept; reserved `status`, `code`, and `phone_number` values are replaced. Expired, replayed or missing state without a trusted destination shows a local 400 error instead of redirecting. A revoked app scheme also uses a local error. Never accept a return destination from callback query parameters.

## Response fields

`200` returns the following shape.

| Field | Type | Meaning |
| --- | --- | --- |
| `url` | string | Always returned. |
| `expires_at` | string | Always returned. |

The URL is short-lived and private. Do not log or cache it.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status / code | What it means | What to do |
| --- | --- | --- |
| 400 · `invalid_return_url` | The return destination is not allowed. | Use HTTPS or an approved app scheme; remove forbidden URL parts. |
| 401 · `unauthorized` | The credential is missing or invalid. | Check the full account credential and API host privately; stop the retry loop. |
| 403 · `permission_denied` | This actor cannot perform the operation. | Resolve the account or role restriction through an authorised person. |
| 403 · `account_unavailable` | The account is unavailable for this operation. | Resolve the account or role restriction through an authorised person. |
| 404 · `number_not_found` | The number is absent or inaccessible to this account. | Check the exact owned identifier and current resource state; do not probe another account. |
| 409 · `already_connected` | This number already has a calendar connection. | Read the connection status; do not create another consent flow for an already connected number. |
| 409 · `booking_provider_conflict` | Another booking provider is active. | Choose one provider and disconnect the unwanted connection deliberately. |
| 409 · `agent_not_assigned` | The number has no eligible agent. | Assign an eligible owned agent to this number before connecting the calendar. |
| 409 · `expired_link` | The consent or connection state is no longer current. | Start a fresh consent flow after checking the current connection. |
| 429 · `rate_limit_exceeded` | The request limit was reached. | Stop automatic retries; wait for the limit and reconcile state before a deliberate action. |
| 503 · `calendar_unavailable` | The calendar operation or status check could not be completed. | Treat the outcome as uncertain and read the affected resource before another deliberate change. |
| 503 · `not_configured` | The required service configuration is unavailable. | Ask the operator to complete the required service configuration. |
| 503 · `guard_unavailable` | The access check could not be completed. | Wait for the access check to recover; do not bypass it. |

A Member dashboard session cannot connect. Read status after a lost response before creating another consent link.

## Retry and idempotency

Disable automatic write retries. A lost response leaves the result uncertain; read the affected resource before another deliberate action. No general Idempotency-Key replay guarantee applies. See [retry rules](/api-reference/retries).
