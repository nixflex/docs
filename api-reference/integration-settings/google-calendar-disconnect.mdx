Disconnect Google Calendar from an owned Nixflex number. Remove local access and understand in-flight bookings and shared Google grants.

## Authentication

Use `Authorization: Bearer KEY_ID:KEY_SECRET` for the owning account. An organisation API key has Owner authority. Personal sessions use the role rules documented in [Authentication](/api-reference/authentication); do not treat a Member session as an API key.

## Request fields

| Field | Type | Required | Default and limits |
| --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | Owned E.164 number. URL-encode the leading +. |

Do not send a request body.

Local access is removed for this number, including its older agent-wide calendar fallback. Other numbers keep their access. Remote Google revocation is best effort and can be skipped where grants may be shared. Already-loaded booking tools check the stored connection before a write; an operation already dispatched cannot be recalled.

## Response fields

`200` returns the following shape.

| Field | Type | Meaning |
| --- | --- | --- |
| `ok` | boolean | Always returned. |
| `connected` | boolean | Always returned. |

A successful local disconnect returns exactly `ok: true, connected: false`.

## Errors

Branch on `error.code`, not the wording of `error.message`. The envelope includes `type`, `code`, `message`, `doc_url` and `details`.

| Status | Meaning |
| --- | --- |
| 401 | unauthorized. Standard error envelope; branch on error.code. |
| 403 | permission_denied, account_unavailable. Standard error envelope; branch on error.code. |
| 404 | number_not_found. Standard error envelope; branch on error.code. |
| 409 | expired_link. Standard error envelope; branch on error.code. |
| 429 | rate_limit_exceeded. Standard error envelope; branch on error.code. |
| 503 | calendar_unavailable. Standard error envelope; branch on error.code. |

Read status after a lost response before another deliberate disconnect.

## Retry and idempotency

Disable automatic write retries. A lost response leaves the result uncertain; read the affected resource before another deliberate action. No general Idempotency-Key replay guarantee applies. See [retry rules](/api-reference/retries).
