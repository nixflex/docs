Change only supplied fields of one owned custom function. Omitted fields keep their saved values; this does not create a missing function.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential. When personal dashboard sessions are enabled, Owner and Admin sessions can write these settings; Member sessions can read only. Ownership checks still apply. Send `Content-Type: application/json`.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | None | Owned E.164 number. URL-encode the leading plus sign. |
| `id` (path) | string | Yes | None | Custom function ID returned by create or list for this number. |

Send a JSON object.

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `name` | string | No | Unchanged | Lowercase snake_case function name. Maximum 64 characters. Pattern: `^[a-z][a-z0-9_]*$`. |
| `description` | string | No | Unchanged | Description supplied to the agent. |
| `url` | string | No | Unchanged | HTTPS destination; required on create. |
| `method` | string | No | Unchanged | Uppercased before validation. Allowed: `"GET"`, `"POST"`, `"PUT"`, `"PATCH"`, `"DELETE"`. |
| `headers` | object | No | Unchanged | Private HTTP headers. GET returns only has_headers. |
| `parameters` | object | No | Unchanged | Function parameter JSON schema. |
| `speak_during` | string or null | No | Unchanged | Optional phrase; a falsey value clears it. |
| `timeout_ms` | integer | No | Unchanged | Parsed as an integer and clamped to 1,000–45,000 ms. Zero or nonnumeric values fall back to 5,000. |
| `is_active` | boolean | No | Unchanged | Only literal false disables the function. |

Headers are private and never returned by the list route. Timeout inputs are parsed and clamped; the stored range is 1,000–45,000 ms. A supplied falsey description becomes an empty string, falsey headers become an empty object, falsey parameters restore the default schema, and falsey speak_during clears the phrase.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `ok` | boolean | Request succeeded. Value: `true`. |
| `id` | string | Function identifier. |
| `phone_number` | string | Owned phone number. |
| `name` | string | Saved function name. |

## Example request

These examples use the unpublished Node/CLI 0.10.0, Python 0.3.0 and MCP 0.4.0 candidates. Keep the staging key in `NXF_STAGING_KEY`; the PowerShell CLI reads it through `NIXFLEX_API_KEY`. The cURL example uses Bash. Use approved owned fixtures and keep configuration responses private. Python shows sync usage; AsyncNixflex uses the same method with async with and await. Configure the existing MCP installation for the same account and staging host. Save the request JSON fields from the example below in request-49.json privately before using cURL or CLI; replace fixture credentials only in that private file. Review the target and payload before this write.

```json request-49.json
{
  "description": "",
  "headers": {},
  "speak_during": null,
  "is_active": false,
  "timeout_ms": 45001
}
```

<RequestExample>

```bash cURL
curl --request PATCH \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/integrations/custom-functions/number/%2B12025550123/11111111-1111-4111-8111-111111111111" \
  --header "Authorization: Bearer $NXF_STAGING_KEY" \
  --header "Content-Type: application/json" \
  --data-binary @request-49.json
```

```javascript Node
import { Nixflex } from 'nixflex';
const c = new Nixflex({apiKey:process.env.NXF_STAGING_KEY,baseUrl:'https://nixflex-voice-engine-staging.up.railway.app',maxRetries:0});
const result = await c.integrations.updateFunction("+12025550123", "11111111-1111-4111-8111-111111111111", {"description": "", "headers": {}, "speak_during": null, "is_active": false, "timeout_ms": 45001});
// Keep private responses out of logs and AI conversations.
```

```python Python
import os
from nixflex import Nixflex
with Nixflex(api_key=os.environ["NXF_STAGING_KEY"], base_url="https://nixflex-voice-engine-staging.up.railway.app", max_retries=0) as c:
    result = c.integrations.update_function('+12025550123', '11111111-1111-4111-8111-111111111111', description='', headers={}, speak_during=None, is_active=False, timeout_ms=45001)
```

```powershell CLI (PowerShell)
$env:NIXFLEX_API_KEY = $env:NXF_STAGING_KEY
# Save the documented JSON fields privately as request-49.json first.
nixflex integrations updateFunction '+12025550123' 11111111-1111-4111-8111-111111111111 --body '@request-49.json' --confirm --json --base-url "https://nixflex-voice-engine-staging.up.railway.app"
```


</RequestExample>

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

| 400 | [`invalid_phone`](/api-reference/errors#invalid_phone) | The number is not valid E.164. | Correct the request before retrying. |

## Retry and idempotency

No idempotency token is supported. Read the function list after a timeout before resending. Creation can conflict with an existing name, and repeating a delete may remove a function recreated under the same ID.
