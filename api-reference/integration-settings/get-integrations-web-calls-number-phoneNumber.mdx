Read the saved web calls setting for an owned number. This controls the saved number switch for website voice calls. Reading or changing the switch does not start a call.

- Read the current setting for this exact owned target before changing it.
- A saved web-call configuration is not proof a browser session connected.

## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential. When personal dashboard sessions are enabled, Owner and Admin sessions can write these settings; Member sessions can read only. Ownership checks still apply.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `phoneNumber` (path) | string | Yes | None | Owned E.164 number. URL-encode the leading plus sign. |

Do not send a request body.

The GET response reports the saved number flag, not the full effective website availability. Agent settings and environment availability can still prevent a website call. The website Web agent must also be on. Read phone-number details for web_calls_effective; account, agent and billing checks still apply.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `phone_number` | string | Owned phone number. |
| `web_calls_enabled` | boolean | Saved number switch. |

## Example request

Examples use the supplied, unpublished Node/CLI 0.11.0, Python 0.4.0 and MCP 0.5.0 candidates. Keep the staging key in `NXF_STAGING_KEY`; the PowerShell CLI reads it through `NIXFLEX_API_KEY`. The cURL example uses Bash. Use approved owned fixtures and keep configuration responses private. Python shows sync usage; AsyncNixflex uses the same method with async with and await. Configure the existing MCP installation for the same account and staging host.

<RequestExample>

```bash cURL
curl --request GET \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/integrations/web-calls/number/%2B12025550123" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';
const c = new Nixflex({apiKey:process.env.NXF_STAGING_KEY,baseUrl:'https://nixflex-voice-engine-staging.up.railway.app',maxRetries:0});
const result = await c.integrations.get("web-calls", "+12025550123");
// Keep private responses out of logs and AI conversations.
```

```python Python
import os
from nixflex import Nixflex
with Nixflex(api_key=os.environ["NXF_STAGING_KEY"], base_url="https://nixflex-voice-engine-staging.up.railway.app", max_retries=0) as c:
    result = c.integrations.get('web-calls', '+12025550123')
```

```powershell CLI (PowerShell)
$env:NIXFLEX_API_KEY = $env:NXF_STAGING_KEY
nixflex integrations get web-calls '+12025550123' --json --base-url "https://nixflex-voice-engine-staging.up.railway.app"
```

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 404 | [`not_found`](/api-reference/errors#not_found) | No matching owned resource or saved configuration was found. | Check the identifier and owning account. |
| 500 | [`server_error`](/api-reference/errors#server_error) | The result could not be confirmed. | Read the current state before retrying a write. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

This is a read-only request. Retry transient connection or server failures with bounded backoff; respect Retry-After for 429. Do not retry validation or ownership errors unchanged. A later read can return newer state.
