Build voice, messaging, and knowledge workflows with the Nixflex API. Requests use HTTPS and the versioned base URL `https://api.nixflex.com/v1`.

## Start here

1. Read [Authentication and permissions](/api-reference/authentication).
2. [Create an agent](/api-reference/agents/create), then read it back using its returned ID.
3. Choose the resource page for the operation you need.
4. Handle [errors](/api-reference/errors), [paging](/api-reference/pagination), and [uncertain write results](/api-reference/retries) explicitly.

## Requests and responses

Send `Authorization: Bearer KEY_ID:KEY_SECRET` from your server. JSON bodies use `Content-Type: application/json`. Keep credentials out of browser code, URLs, repositories, and logs.

A resource ID belongs to the authenticated account. Use the ID returned by the API; a display name is not an ID. Phone numbers use international E.164 format and must be URL-encoded in paths.

Successful statuses and response shapes vary by operation. Some lists are bare arrays; others contain items and a cursor. A `202` response means accepted work, not completed work. Poll the documented job or resource read until its result is known.

## Supported scope

The public reference covers accounts and keys, agents, voices, phone numbers, calls, campaigns, SMS, contact controls, caller context, web agents, inboxes, knowledge, organisations, and integration settings. A product feature does not automatically provide a public API operation. Only documented public operations belong in an integration.

The [public OpenAPI file](/api-reference/public.openapi.json) is a bundled foundation. It describes the operations currently included in that file; it does not claim that every future resource page is complete. Existing resource pages remain available while the reference expands.

## Normal agent defaults

A new agent has a maximum call duration of **300 seconds**, a silence hang-up delay of **10 seconds**, and **dynamic greeting enabled**. An existing agent keeps its stored settings when a field is omitted from an update. See the [agent contract](/api-reference/agents/contract) and [versioning and changelog](/api-reference/versioning).

## Environments

Production uses `https://api.nixflex.com/v1`. A staging key belongs to its staging service and must not be sent to production. Examples use placeholders. Set the correct base URL and key together.
