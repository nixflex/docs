## Authentication

Send Authorization: Bearer KEY_ID:KEY_SECRET using the owning account’s server-side API credential. API keys have Owner authority. Personal Owner and Admin may perform this action; Member is refused. Personal dashboard visibility can hide API-origin agents. Never send owner fields to select another account.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `kb` (path) | string | Yes | None | Opaque identifier. Keep it as a string. Format: uuid. |

Send a JSON object.

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `query` | string | Yes | None | Trimmed management search text. Maximum 200 characters. Minimum 2 characters. |

This POST performs a semantic search, not public call retrieval. It needs no Idempotency-Key and does not change topics. Up to 30 related pieces are returned; use local word filtering when semantic search is unnecessary. Only similarities of at least 0.25 are returned, ordered highest first. An empty live base returns an empty items array and the revision.

## Example request

These examples target Node/CLI 0.11.0 and Python 0.4.0; confirm the installed version supports the method before use. The cURL tab uses Bash; CLI uses PowerShell. Python shows sync usage; AsyncNixflex uses the same JSON methods with async with and await. Set the account credential in `NIXFLEX_API_KEY` and the owned path identifiers shown below in environment variables. Submit this calculation deliberately.

```json request-117.json
{
  "query": "appointment times"
}
```

<RequestExample>

```bash cURL (Bash)
curl --request POST \
  --url "https://api.nixflex.com/v1/knowledge-bases/$(node -p 'encodeURIComponent(process.env.NXF_KNOWLEDGE_BASE_ID)')/topic-search" \
  --header "Authorization: Bearer $NIXFLEX_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"query":"appointment times"}'
```

```javascript Node
import { Nixflex } from 'nixflex';
const c = new Nixflex({apiKey:process.env.NIXFLEX_API_KEY,baseUrl:'https://api.nixflex.com',maxRetries:0});
const result = await c.knowledge.searchTopics(process.env.NXF_KNOWLEDGE_BASE_ID, {"query":"appointment times"});
// Keep knowledge and private results out of logs.
```

## Retry and idempotency

This is a read or calculation. GET requests may retry transient connection failures once with bounded backoff; respect Retry-After. Do not retry invalid input or ownership errors unchanged. POST calculations are not automatically retried.
