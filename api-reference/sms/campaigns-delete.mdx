## Authentication

Send `Authorization: Bearer KEY_ID:KEY_SECRET` using the owning account’s server-side credential.

## Request fields

| Field | Type | Required | Default | Limits and meaning |
| --- | --- | --- | --- | --- |
| `id` (path) | string | Yes | None | Exact saved campaign_id owned by this account. This operation does not declare a route-level length or character validator. |

Do not send a request body.

No body is used. A missing owned campaign returns 200 with the same acknowledgement. Running work returns 409 campaign_in_progress: cancel or wait first. Unsettled final results or charges return 409 campaign_settlement_pending with details.deleted=false. Keep the campaign row until confirmed success and show the safe server message. Zero sent is not proof that there is no active, unknown or unsettled work. Deletion does not recall accepted messages or prove erasure of all copies. The CLI may read detail for its confirmation preview.

## Response fields

`200 OK` returns the shape below. Nullable fields can be unknown or unset; do not turn null into zero or false.

| Field | Type | Meaning |
| --- | --- | --- |
| `message` | string | Deletion acknowledgement. |

## Example request

These examples use the supplied client candidates: Node/CLI 0.11.0, Python 0.4.0 and MCP 0.5.0. Keep `NXF_STAGING_KEY` private. cURL uses Bash; CLI uses PowerShell and reads the key through `NIXFLEX_API_KEY`. Replace fixture identifiers and reserved example numbers with approved account-owned values. Configure the existing MCP installation for the same staging host and account before using the shown tool arguments. Python shows the synchronous client; `AsyncNixflex` uses the same method with `async with` and `await`. This example changes state. Review the target and payload before running it.

<RequestExample>

```bash cURL
curl --request DELETE \
  --url "https://nixflex-voice-engine-staging.up.railway.app/v1/sms/campaigns/campaign_fixture" \
  --header "Authorization: Bearer $NXF_STAGING_KEY"
```

```javascript Node
import { Nixflex } from 'nixflex';

const c = new Nixflex({
  apiKey: process.env.NXF_STAGING_KEY,
  baseUrl: 'https://nixflex-voice-engine-staging.up.railway.app',
  maxRetries: 0,
});
const result = await c.sms.campaigns.delete("campaign_fixture");
```

```python Python
import os

with Nixflex(
```

## Errors

Failures return an `error` object with `code`, `message`, `doc_url` and optional details. Each code links to the shared error catalog. Read the message and details before deciding whether to resend.

<div className="agent-error-table">

| Status | Code | Meaning | What to do |
| --- | --- | --- | --- |
| 409 | [`campaign_in_progress`](/api-reference/errors#campaign_in_progress) | This campaign is still running. Cancel it or wait for it to finish before deleting it. | Keep the row; cancel or wait for completion before a deliberate deletion. |
| 409 | [`campaign_settlement_pending`](/api-reference/errors#campaign_settlement_pending) | This campaign is waiting for its final send results and charges. It has not been deleted. Try again after settlement finishes. | details.deleted is false. Keep the row and wait for settlement; never report deletion. |
| 503 | [`deletion_unavailable`](/api-reference/errors#deletion_unavailable) | Deletion could not be checked. No deletion was confirmed. | Read current state and reconcile the uncertain outcome before another deliberate write. |
| 401 | [`unauthorized`](/api-reference/errors#unauthorized) | The credential is missing or invalid. | Check the account credential and environment. |
| 429 | [`rate_limit_exceeded`](/api-reference/errors#rate_limit_exceeded) | The account request limit was reached. | Wait for Retry-After. Reconcile uncertain writes before resending. |

</div>

## Retry and idempotency

No idempotency key is documented. A timeout or 5xx can follow a committed change. Read the current state before deciding whether to submit again; never automatically repeat an uncertain write. Repeating deletion of an already absent ID returns 200, but an earlier unknown request still needs state reconciliation.
