---
title: "List SMS campaigns"
description: "GET /v1/sms/campaigns"
api: "GET https://api.nixflex.com/v1/sms/campaigns"
---

Returns all SMS campaigns for your account, newest first.

## Request

```bash
curl https://api.nixflex.com/v1/sms/campaigns \
  -H "Authorization: Bearer KEY_ID:KEY_SECRET"
```

## Query parameters

| Parameter | Type | Notes |
|---|---|---|
| `limit` | int | Default 25, max 100 |
| `offset` | int | Pagination offset |
| `agent_id` | string | Filter to one agent |
| `status` | enum | `scheduled`, `running`, `completed`, `cancelled` |
