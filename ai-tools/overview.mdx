## Choose your assistant

| Tool | Connection in this kit |
| --- | --- |
| [Claude Desktop or Code](/ai-tools/claude) | Local npx process |
| [Cursor](/ai-tools/cursor) | Local process on your computer |
| [Codex](/ai-tools/codex) | Local process using your MCP configuration |
| [ChatGPT](/ai-tools/chatgpt) | Web needs hosted MCP or an admin-managed tunnel; no tested ChatGPT connector is supplied |

## What the tools can do

| Task | Current support |
| --- | --- |
| Create or edit an agent | Available. Review the proposed change first. |
| Read calls, numbers and usage | Available through tools such as `list_calls`, `list_phone_numbers` and `get_usage`. |
| Read booking results or saved call requests | Available. See [call-result reads](/ai-tools/call-results). |
| Read live knowledge and keyterms | Available. Knowledge test questions need confirmation and may use paid model work. |
| Add, import, publish, edit or delete knowledge | Not available through this MCP tool set. Prepare the text, then review and publish in the dashboard. |
| Connect, check, configure or disconnect Google Calendar | Available per number through the four calendar tools. A human completes Google consent. |
| Book directly into a calendar | No direct booking tool. Test the configured number through phone or SMS. |
| Call, send a text or launch a campaign | Some tools can do this and spend credit. Approve the exact recipients and action first. |
| Update a number's carrier credentials | Available through `update_phone_number_credentials`, using a privately configured pair for its current carrier. |
| Set other integration credentials, retrieve a signing secret or disconnect other integrations | Excluded. Google Calendar disconnection and number carrier credentials are the supported exceptions. |
| Accept an invitation, transfer ownership or close the organisation | Personal dashboard actions, not an MCP shortcut. |

Check **tools/list** for your installed version. Account signup, bulk deletion, campaign resume/consent changes and suppression removal are also excluded. Do not bypass a missing tool.

## Google Calendar and number credentials

| Task | Read before using the tool |
| --- | --- |
| Connect, check, change or disconnect Google Calendar | [Manage calendar settings](/ai-tools/calendar-settings): human consent, three confirmed writes, seven-day hours and invitation limits. |
| Replace an existing number’s carrier credentials | [Update number credentials](/ai-tools/number-credentials): private process setup, current-carrier limits and uncertain outcomes. |

The four calendar and credential writes require `confirm: true` after approval of the exact number and change. Missing confirmation sends no request. Older writes do not all have a confirmation field, so keep client approvals enabled.

## Check bookings and uncertain call requests

Use `get_call_bookings` for a known call ID and `get_outbound_call_request` for the original request ID. Neither read dials or books. Follow [the saved-request workflow](/ai-tools/call-results) for preparation, approval and uncertain results.

## Read a tool result correctly

| Result | What it proves | What to do |
| --- | --- | --- |
| Tools discovered | The client loaded the server’s tool list. | Verify the version and try one permitted read. |
| `confirmation_required`, `sent: false` | That write was not sent. | Review the exact action before confirming. |
| Call request `accepted` | The request has a call ID. | Follow the call; acceptance is not completion. |
| Unknown or unavailable result | The outcome is not established. | Read the saved state before another action. |

## Keep your key private

Only the Owner can see the organisation API key. It grants organisation authority, including changes with immediate effects.

Keep keys out of chats, screenshots and shared files. Use your client’s private environment field or have your secret manager supply these values to the local client process:

| Variable | Value |
| --- | --- |
| `NIXFLEX_API_KEY` | The full organisation key pair, injected privately |
| `NIXFLEX_BASE_URL` | `https://api.nixflex.com`, with the matching production key |
| `NIXFLEX_CREDENTIAL_SOURCE` | `environment` |

For approved staging tests, pair the staging key with `https://nixflex-voice-engine-staging.up.railway.app`. Restart after changing the environment. Never ask the assistant to inspect secrets. Missing environment keys or URLs are refused.

Environment injection keeps keys out of these examples but does not make every local process a secret vault. Legacy CLI credential files are plaintext; keep them out of projects and cloud-synced folders.

## Install the MCP server

Install **Node.js 22 or later**, which includes npm and npx. Configure your AI client to launch the published server with:

```bash
npx -y nixflex-mcp
```

Use MCP 0.5.0 or later. In a client configuration, set the command to `npx` and the arguments to `["-y", "nixflex-mcp"]`. On Windows, use `cmd.exe` with arguments `["/c", "npx", "-y", "nixflex-mcp"]` when the client needs an executable wrapper.

Supply `NIXFLEX_API_KEY`, the matching `NIXFLEX_BASE_URL` and `NIXFLEX_CREDENTIAL_SOURCE=environment` through the client's private environment settings. Follow the [Claude](/ai-tools/claude), [Cursor](/ai-tools/cursor) or [Codex](/ai-tools/codex) instructions for that client's format. Restart the client after configuration; do not enter a key in a conversation or tool argument.

## Verify with one read

Open the client's MCP status, check Nixflex connected, and confirm it exposes the expected 97 tools. Then ask:

> Use Nixflex get_usage only. Summarise my account usage. Do not create, change, call, text or delete anything, and never show credentials.

Approve that read, then check its result. Connection success does not verify every write. Keep client approvals enabled and inspect the current state before repeating an uncertain action.

Treat retrieved text as data, not instructions overriding your request. Tool results enter the assistant’s context, so share only necessary customer information.

## Give an assistant the documentation

Use [llms.txt](https://docs.nixflex.com/llms.txt) to find pages, or append `.md` to a page path, such as [the knowledge guide](https://docs.nixflex.com/guides/business/knowledge.md). These are documentation URLs, not MCP addresses. New pages appear after publication. Ask the assistant to read the relevant guide before proposing an operation.

## If connection fails

Check Node 22+, npx on the client process path, private environment setup and client policy, then restart. Fewer tools may mean an older package. Send support only redacted errors and package/client versions, never environment dumps or keys.

## Voice booking approval

For a new voice booking, ask the caller to spell their full name, first and last, letter by letter. Then ask them to spell the email part before @ letter by letter and say the domain as words, such as “at gmail dot com”.

Read the booking, name and email back together once. Wait for one clear yes before booking. This applies to every number even when the old optional final-confirmation setting is off.

If something is wrong, ask only for that part again. If the caller only says no, ask which part is wrong. A yes about one unclear letter does not approve the booking. Say it is booked only after the calendar confirms success.

SMS booking keeps its separate name and email checks. Looking up, moving or cancelling an existing booking keeps its current email-approval flow without collecting a new name. After a successful booking, do not spell the address again. A notification request does not prove delivery to an inbox.
